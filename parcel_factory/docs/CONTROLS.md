# 택배 공장 조작표

모바일 가로 화면 기준이고, PC도 같은 화면이에요. 키보드·마우스는 `project.godot`의 InputMap 액션으로 받아요.
조작이 바뀌면 이 표도 같이 고쳐요.

## 공통 판정

| 이름 | 값 | 어디 |
|---|---|---|
| 꾹 | 0.35초 누르고 있기 | `Player.HOLD_SEC` |
| 끌기 | 꾹 판정 전에 12px 넘게 움직임 = 둘러보기 (꾹이 아니에요) | `EditController.DRAG_PX` |
| 꾹 게이지 | 월드를 누르는 동안 손가락 위 작은 원, 상호작용 버튼은 테두리가 0.35초에 다 차요 | `hud.HoldRing` · `ActionButton.HOLD_SEC` |
| 대상 고정 | 상호작용 대상은 새 후보가 0.15초 동안 계속 가장 좋아야 바뀌어요 (PC 마우스는 바로) | `Player.TARGET_LOCK_SEC` |
| 상호작용 거리 | 플레이어 중심 3칸 | `Player.REACH` |
| 설치·철거·이동 거리 | 플레이어에서 8칸 (밖이면 '너무 멀어요'·'거리') | `Main.BUILD_RANGE` |
| 철거 게이지 | 0.6초 (20개 넘게 한 번에 = 1.2초) | `EditController.DECON_SEC` · `DECON_SEC_MANY` |
| 철거·이동 불가 | 지급 설비 · 지형(쓰레기 더미·물 샘) | `Factory.can_deconstruct` |

## 기본

| 동작 | 모바일 | PC |
|---|---|---|
| 걷기 · 달리기 | 조이스틱(조금 밀면 아주 천천히, 제곱 곡선) · 끝까지 밀기 | WASD·방향키 · Shift |
| 상호작용 | 상호작용 버튼 (바라보는 대상) · 손 닿는 설비 탭 | F · 마우스 왼쪽 (마우스를 올린 칸이 대상) |
| 핫바 | 핫바 탭 | 1~9 |
| 가방 | 가방 버튼 · 핫바를 위로 쓸기 | E · Tab |
| 회전 | 회전 버튼 · 두 번째 손가락 탭 | R |
| 모드 | 모드 묶음 [일반][이동][철거] | Z 일반 · X 이동 · C 철거 |
| 확대·축소 (0.5~3배, 저장) | 두 손가락 | 휠 |
| 둘러보기 | 조이스틱 영역 밖 월드를 누르자마자 끌기 (떼고 1.5초 뒤 플레이어에게) | 마우스 가운데 버튼 끌기 |
| 취소 | — | Esc · 마우스 오른쪽 |
| 저장 · 디버그 | 메뉴 | Ctrl+S · F3 |
| 다음 날 (18:00 '하루 끝' 창) | [다음 날] 버튼 | 클릭 |

취소 순서: 가방·메뉴 닫기 → 설치 취소 → 옮기기·철거 게이지·범위 선택 취소 → 선택 해제 → 일반 모드 → 하던 일·든 것 내려놓기.

## 일반 모드

| 동작 | 모바일 | PC |
|---|---|---|
| 정보창 | 손 닿는 설비 탭 (멀면 테두리 깜빡임 + '가까이 가야 해요') | 클릭 |
| 빠른 넣기 | 아이템을 들고 설비 꾹 | 같음 |
| 더미 뒤지기 · 휘두르기 | 더미 꾹 · 맨손 꾹 | 같음 |
| 설치 | 설비 아이템을 들고 상호작용 버튼 꾹 → 끌어 조준 → 떼기 (가운데 X로 되돌아와 떼면 취소) | 미리보기가 마우스를 따라가요 · 왼쪽 클릭 |
| 연속 설치 (설정 → 연속 설치 켬) | 상호작용 버튼 꾹 → 끌면 지나가는 칸마다 (레일·파이프·전선은 두 점 방식 그대로) | 왼쪽 버튼 누른 채 끌기 |
| 레일·파이프·전선 | 두 점 설치: A 놓기 → B 놓기 (직선·ㄱ자) | 두 번 클릭 |

## 철거 모드

| 동작 | 모바일 | PC |
|---|---|---|
| 철거 | 설비 꾹 → 원형 게이지가 차면 철거 (중간에 떼면 취소) | 왼쪽 버튼 꾹 |
| 가까운 설비 | 상호작용 버튼 꾹 = 지금 대상(흰 테두리)을 같은 게이지로 | F 꾹 |
| 탭 | '꾹 눌러서 철거' 안내만 (정보창은 안 열려요) | 클릭 |

철거하면 안의 아이템과 설비 제작 재료가 그 자리에 쏟아져요 (부서짐 효과·소리).

## 이동 모드

| 동작 | 모바일 | PC |
|---|---|---|
| 옮기기 | 설비 꾹 → 들려서 손가락을 따라옴 → 떼면 그 칸으로 | 왼쪽 버튼 꾹 → 끌기 → 놓기 |
| 가까운 설비 | 상호작용 버튼 꾹 → 버튼을 끌어 조준 → 떼기 (가운데 X로 되돌아와 떼면 취소) | F 꾹 |
| 옮기는 중 회전 | 회전 버튼 · 두 번째 손가락 탭 | R |
| 탭 | '꾹 눌러서 옮기기' 안내만 | 클릭 |

- 안의 아이템·레시피·설정·방향은 그대로예요. 레일을 옮기면 위의 물건도 같이 가요.
- 옮기는 동안 그 설비는 멈추고, 원래 자리는 점선 테두리로 보여요.
- 다른 설비·벽·통로·지형 위이거나 거리 밖에 놓으면 취소되고 제자리로 스르륵 돌아가요 (자기 원래 자리와 겹치는 건 괜찮아요).
- 전선·파이프는 제자리에 남아요 (층 보기를 켜고 범위 선택에 넣었을 때만 같이 가요).

## 범위 선택 (모든 모드)

| 동작 | 모바일 | PC |
|---|---|---|
| 선택 | 설비 없는 빈 칸 꾹 → 끌어서 사각형 → 놓기 | 빈 곳 왼쪽 버튼 꾹-끌기 |
| 더하기 | 다시 빈 곳 꾹-끌기 = 새 선택으로 교체 | Shift + 꾹-끌기 = 더하기 |
| 해제 | 선택 안 된 곳 탭 · 선택 바 [해제] | 오른쪽 클릭 · Esc |
| 묶음 철거 | 철거 모드에서 선택된 설비 하나 꾹 (게이지 옆 'N개 철거') · 선택 바 [철거(꾹)] | Delete |
| 묶음 옮기기 | 이동 모드에서 선택된 설비 하나 꾹 → 끌기 · 선택 바 [이동] 뒤 월드를 눌러 끌기 | 같음 |

- 들어가는 것: 설비·레일. 바닥 아이템과 철거 불가 목록은 빠져요. 전선·파이프는 층 보기를 켰을 때만.
- 사각형은 화면에 보이는 곳 어디든 돼요. 끄는 손가락이 화면 가장자리 15%에 닿으면 카메라가 그쪽으로 가요 (손을 떼고 1.5초 뒤 플레이어에게 돌아와요).
- 거리는 실행할 때 잡은 설비(선택 바·Delete는 플레이어에게 가장 가까운 선택 설비) 기준으로만 봐요.
- 묶음 옮기기는 상대 배치를 그대로 두고 평행 이동만 해요. 하나라도 막히면 전체가 빨강이고, 그대로 놓으면 전부 제자리로.
- 선택 상태: 선택된 설비마다 노란 테두리, 화면 위에 '설비 N개 선택됨' + [이동][철거(꾹)][해제].

## 카메라

- 플레이어를 부드럽게 따라가요 (데드존 1칸: 그 안에서 움직이면 화면이 가만히 있어요). 달리면 진행 방향으로 1.5칸 앞을 보여줘요.
- 설치·이동·범위 선택 중 손가락(또는 미리보기)이 화면 가장자리 15%에 닿으면 카메라가 그쪽으로 천천히 가요.
- 카메라 위치는 화면 픽셀에 맞춰 반올림해서 도트가 떨리지 않아요.

## 손맛

- 미리보기(설치·이동)가 한 칸 옮겨 갈 때마다 가벼운 '틱' 소리와 아주 짧은 진동.
- 벽·설비 모서리에 살짝 걸리면 옆으로 미끄러져 지나가요 (코너 보정, 0.4칸까지).
- 모든 버튼: 누르는 동안 95% 크기 + 조금 밝게, 소리는 `assets/sfx/button` (없으면 무음).

## 손동작 구분 (헷갈리지 않게)

월드를 손가락 하나로 누르면 이렇게 갈라져요:

```
누름 ─┬─ 0.35초 전에 12px 넘게 움직임 ──→ 둘러보기 (카메라만 움직여요. 탭·꾹은 없어요)
      ├─ 0.35초 전에 뗌 ─────────────────→ 탭
      │     선택이 있고 선택 밖이면 → 선택 해제만
      │     일반: 손 닿는 설비 = 정보창, 먼 설비 = 깜빡임 / 이동·철거: 안내 말풍선
      └─ 0.35초 넘게 누름 ───────────────→ 꾹
            빈 칸 → 범위 선택 (모든 모드)
            일반: 손 닿는 설비 → 들고 꾹 = 빠른 넣기 · 더미 뒤지기 · 맨손 = 휘두르기
            철거: 설비 → 철거 게이지 (선택된 설비면 선택 전체)
            이동: 설비 → 들어서 옮기기 (선택된 설비면 선택 전체)
```

서로 겹칠 수 있던 곳과 정한 규칙:

| 겹치는 곳 | 규칙 |
|---|---|
| 조이스틱 영역 (왼쪽 35% × 아래 60%) | 거기서 누르면 언제나 조이스틱. 둘러보기·범위 선택·꾹은 그 밖에서 시작해요 (시작한 손가락은 조이스틱 위를 지나가도 안 끊겨요). |
| 두 번째 손가락 | 꾹 동작(게이지·옮기기·범위 선택) 중이면 짧은 탭 = 회전(옮길 때), 아니면 두 손가락 = 확대·축소. 둘러보던 손가락에 두 번째가 오면 확대·축소로 바뀌어요. |
| 설치 중(상호작용 버튼을 누르고 있음) 월드 터치 | 그 칸으로 미리보기 옮기기, 짧은 탭 = 회전. 이때는 둘러보기·확대가 없어요. |
| 버튼 끌기: 조준 ↔ 연속 설치 | 같은 손동작이라 설정으로 골라요. 기본은 조준(연속 설치 꺼짐). 켜면 지나간 칸에 다 놓여요. |
| 설비 아이템을 들고 월드의 설비를 꾹 | 아무 일 없어요. 설치는 상호작용 버튼·F 꾹으로만 해요. (전에는 이 손가락이 설치 모드를 켜 놓고 놓쳐서 설치 모드가 남았어요.) |
| 선택 바 [이동]을 누른 뒤 | 다음 월드 누르기는 바로 들어 옮기기예요 (둘러보기 아님). |
| PC에서 설비 아이템을 든 채 왼쪽 클릭 | 설치예요 (범위 선택 아님). 범위 선택은 Esc로 내려놓고, 둘러보기는 가운데 버튼으로. |
