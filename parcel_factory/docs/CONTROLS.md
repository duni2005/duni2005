# 택배 공장 조작표

모바일 가로 화면 기준이고, PC도 같은 화면이에요. 키보드·마우스는 `project.godot`의 InputMap 액션으로 받아요.
조작이 바뀌면 이 표도 같이 고쳐요.

## 공통 판정

| 이름 | 값 | 어디 |
|---|---|---|
| 꾹 | 0.35초 누르고 있기 | `Player.HOLD_SEC` |
| 끌기 | 꾹 판정 전에 12px 넘게 움직임 (꾹이 아니에요. 10단계 둘러보기 자리) | `EditController.DRAG_PX` |
| 상호작용 거리 | 플레이어 중심 3칸 | `Player.REACH` |
| 설치·철거·이동 거리 | 플레이어에서 8칸 (밖이면 '너무 멀어요'·'거리') | `Main.BUILD_RANGE` |
| 철거 게이지 | 0.6초 (20개 넘게 한 번에 = 1.2초) | `EditController.DECON_SEC` · `DECON_SEC_MANY` |
| 철거·이동 불가 | 지급 설비 · 지형(쓰레기 더미·물 샘) | `Factory.can_deconstruct` |

## 기본

| 동작 | 모바일 | PC |
|---|---|---|
| 걷기 · 달리기 | 조이스틱 · 끝까지 밀기 | WASD·방향키 · Shift |
| 상호작용 | 상호작용 버튼 (바라보는 대상) · 손 닿는 설비 탭 | F · 마우스 왼쪽 (마우스를 올린 칸이 대상) |
| 핫바 | 핫바 탭 | 1~9 |
| 가방 | 가방 버튼 · 핫바를 위로 쓸기 | E · Tab |
| 회전 | 회전 버튼 · 두 번째 손가락 탭 | R |
| 모드 | 모드 묶음 [일반][이동][철거] | Z 일반 · X 이동 · C 철거 |
| 확대·축소 | 두 손가락 | 휠 |
| 취소 | — | Esc · 마우스 오른쪽 |
| 저장 · 디버그 | 메뉴 | Ctrl+S · F3 |

취소 순서: 가방·메뉴 닫기 → 설치 취소 → 옮기기·철거 게이지·범위 선택 취소 → 선택 해제 → 일반 모드 → 하던 일·든 것 내려놓기.

## 일반 모드

| 동작 | 모바일 | PC |
|---|---|---|
| 정보창 | 손 닿는 설비 탭 (멀면 테두리 깜빡임 + '가까이 가야 해요') | 클릭 |
| 빠른 넣기 | 아이템을 들고 설비 꾹 | 같음 |
| 더미 뒤지기 · 휘두르기 | 더미 꾹 · 맨손 꾹 | 같음 |
| 설치 | 설비 아이템을 들고 상호작용 버튼 꾹 → 끌어 조준 → 떼기 (가운데 X로 되돌아와 떼면 취소) | 미리보기가 마우스를 따라가요 · 왼쪽 클릭 |
| 레일·파이프·전선 | 두 점 설치: A 놓기 → B 놓기 (직선·ㄱ자) | 두 번 클릭 |

## 철거 모드

| 동작 | 모바일 | PC |
|---|---|---|
| 철거 | 설비 꾹 → 원형 게이지가 차면 철거 (중간에 떼면 취소) | 왼쪽 버튼 꾹 |
| 가까운 설비 | 상호작용 버튼 꾹 = 지금 대상(흰 테두리)을 같은 게이지로 | F 꾹 |
| 탭 | '꾹 눌러서 철거' 안내만 (정보창은 안 열려요) | 클릭 |

철거하면 안의 아이템과 설비 제작 재료가 그 자리에 쏟아져요 (부서짐 효과·소리).

## 이동 모드

| 동작 | 모바일 | PC |
|---|---|---|
| 옮기기 | 설비 꾹 → 들려서 손가락을 따라옴 → 떼면 그 칸으로 | 왼쪽 버튼 꾹 → 끌기 → 놓기 |
| 가까운 설비 | 상호작용 버튼 꾹 → 버튼을 끌어 조준 → 떼기 (가운데 X로 되돌아와 떼면 취소) | F 꾹 |
| 옮기는 중 회전 | 회전 버튼 · 두 번째 손가락 탭 | R |
| 탭 | '꾹 눌러서 옮기기' 안내만 | 클릭 |

- 안의 아이템·레시피·설정·방향은 그대로예요. 레일을 옮기면 위의 물건도 같이 가요.
- 옮기는 동안 그 설비는 멈추고, 원래 자리는 점선 테두리로 보여요.
- 다른 설비·벽·통로·지형 위이거나 거리 밖에 놓으면 취소되고 제자리로 스르륵 돌아가요 (자기 원래 자리와 겹치는 건 괜찮아요).
- 전선·파이프는 제자리에 남아요 (층 보기를 켜고 범위 선택에 넣었을 때만 같이 가요).

## 범위 선택 (모든 모드)

| 동작 | 모바일 | PC |
|---|---|---|
| 선택 | 설비 없는 빈 칸 꾹 → 끌어서 사각형 → 놓기 | 빈 곳 왼쪽 버튼 꾹-끌기 |
| 더하기 | 다시 빈 곳 꾹-끌기 = 새 선택으로 교체 | Shift + 꾹-끌기 = 더하기 |
| 해제 | 선택 안 된 곳 탭 · 선택 바 [해제] | 오른쪽 클릭 · Esc |
| 묶음 철거 | 철거 모드에서 선택된 설비 하나 꾹 (게이지 옆 'N개 철거') · 선택 바 [철거(꾹)] | Delete |
| 묶음 옮기기 | 이동 모드에서 선택된 설비 하나 꾹 → 끌기 · 선택 바 [이동] 뒤 월드를 눌러 끌기 | 같음 |

- 들어가는 것: 설비·레일. 바닥 아이템과 철거 불가 목록은 빠져요. 전선·파이프는 층 보기를 켰을 때만.
- 사각형은 화면에 보이는 곳 어디든 돼요. 끄는 손가락이 화면 가장자리 15%에 닿으면 카메라가 그쪽으로 가요 (걸으면 플레이어에게 돌아와요).
- 거리는 실행할 때 잡은 설비(선택 바·Delete는 플레이어에게 가장 가까운 선택 설비) 기준으로만 봐요.
- 묶음 옮기기는 상대 배치를 그대로 두고 평행 이동만 해요. 하나라도 막히면 전체가 빨강이고, 그대로 놓으면 전부 제자리로.
- 선택 상태: 선택된 설비마다 노란 테두리, 화면 위에 '설비 N개 선택됨' + [이동][철거(꾹)][해제].
