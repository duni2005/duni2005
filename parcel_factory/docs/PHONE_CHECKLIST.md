# 폰에서 확인할 것 (Android)

조작 기준은 [`docs/CONTROLS.md`](CONTROLS.md)예요. 한 줄씩 해 보고 □ → ☑로 바꿔 주세요.
안 되는 줄은 "무엇을 했더니 → 무엇이 됐는지"를 적어 보내 주시면 고칠게요.

## 0. 설치

1. Godot 4.3 편집기 → 편집기 → **내보내기 템플릿 관리** → 4.3 템플릿 내려받기.
2. 편집기 설정 → 내보내기 → Android: **Android SDK 경로**, 디버그 키스토어(없으면 편집기가 만들어 줘요).
3. 프로젝트 → 내보내기 → **Android** 프리셋이 이미 있어요 (`export_presets.cfg`).
   - 가로 고정(센서 가로: 폰을 뒤집으면 반대 가로로), 진동 권한, 64비트(arm64), `*.json` 포함, `tests/`·`tools/` 제외.
   - 폰에서는 호환(GL Compatibility) 렌더러로 돌아요 (`rendering_method.mobile`).
4. 폰을 USB로 연결 → 편집기 오른쪽 위 Android 아이콘(원클릭 배포) 또는 **프로젝트 내보내기** → `export/parcel_factory.apk` 설치.

## 1. 처음 시작 (완료 기준 흐름)

- □ 앱을 열면 가로 화면, 큰방 정문 안쪽에 플레이어, 핫바에 시작 지급품(나무 판자·나사·레일 100·전선·테이프·박스).
- □ 노치·둥근 모서리에 버튼이 잘리지 않아요.
- □ 큰방에 공장 짓기: 분해기 등 설비 10개 + 레일 30칸 (아래 3·4).
- □ 지은 것을 범위 선택으로 옮기고(6), 일부를 철거(5).
- □ 출하대로 택배 라인 → 메뉴 → 디버그 → '고용: 초보 배달 아르바이트' → 직원이 출하대 → 정문을 오가고 시계 아래 배달 수가 올라가요(8).
- □ 앱을 껐다 켜면(또는 1분 기다렸다 강제 종료 후 다시 켜면) 그대로 이어져요 (설비·레일 위 물건·바닥 아이템·인벤토리·위치·직원·시계).

## 2. 걷기 · 카메라

- □ 왼쪽 아래(화면 왼쪽 35% × 아래 60%) 아무 데나 누르면 조이스틱이 생기고, 조금 밀면 천천히, 끝까지 밀면 달리기(손잡이 주황).
- □ 벽·설비 모서리에 살짝 걸려도 미끄러져 지나가요.
- □ 카메라가 부드럽게 따라오고, 달리면 앞이 조금 더 보여요. 도트가 떨리지 않아요.
- □ 두 손가락으로 확대·축소(0.5~3배), 앱을 다시 켜도 확대가 그대로.
- □ 조이스틱 영역 밖 월드를 누르자마자 끌면 화면만 움직이고(둘러보기), 떼고 1.5초 뒤 플레이어에게 돌아와요.

## 3. 일반 모드 · 정보창

- □ 손 닿는(3칸) 설비 탭 = 정보창 + 가방, 바깥 탭 = 닫기. 먼 설비 탭 = 노란 테두리 깜빡임 + '가까이 가야 해요'.
- □ 정보창 칸 탭 = 1개, 꾹 = 전부. 레시피 바꾸기. [철거(꾹)].
- □ 아이템을 들고 설비 꾹 = 빠른 넣기. 쓰레기 더미 꾹 = 뒤지기(3초). 맨손 꾹 = 휘두르기.
- □ 월드를 꾹 누르는 동안 손가락 위 작은 원형 게이지, 상호작용 버튼은 테두리 게이지가 차요.

## 4. 설치

- □ 설비 아이템을 들고 상호작용 버튼 꾹 → 끌어서 조준(40px = 1칸, 칸마다 '틱' + 짧은 진동) → 떼면 설치('착' + 진동 + 먼지).
- □ 끌었다가 버튼 가운데(빨간 X)로 돌아와 떼면 취소.
- □ 회전 버튼 · 설치 중 두 번째 손가락 탭 = 회전. 설비마다 마지막 방향 기억.
- □ 막히면 빨강 + 이유(벽·다른 설비·통로·거리·개수 부족).
- □ 레일 두 점: A(깃발) → B 일자/ㄱ자, 회전으로 꺾는 순서, 모자라면 'N개 필요 / M개 있음'. B = A면 A 해제.
- □ 전선·파이프를 들면 층 보기가 켜져요.
- □ (설정 → 연속 설치 켬) 창고 블록을 들고 버튼 꾹-끌기 = 지나간 칸마다 설치.

## 5. 철거 모드

- □ [철거] → 화면 붉은 테두리. 설비 꾹 → 원형 게이지 0.6초 → 재료·내용물이 그 자리에 쏟아지고 파편·소리·진동.
- □ 게이지 중 떼면 취소. 탭 = '꾹 눌러서 철거' 안내만. 지급 설비는 안 돼요.

## 6. 이동 모드 · 범위 선택

- □ [이동] → 설비 꾹 → 손가락을 따라 미리보기(원래 자리 점선) → 놓으면 이동, 안의 아이템·레시피·방향 그대로.
- □ 막힌 곳에 놓으면 빨강 → 0.15초 만에 제자리로.
- □ 빈 칸 꾹 → 끌어서 노란 사각형 → 놓으면 '설비 N개 선택됨' + [이동][철거(꾹)][해제]. 가장자리에 닿으면 카메라가 그쪽으로.
- □ 레일 줄 전체를 선택해 한 번에 옮기기(위 물건도 같이) · 한 번에 철거(20개 넘으면 게이지 1.2초).
- □ 선택 밖 탭 = 해제.

## 7. 상태 · 하루

- □ 돌고 있는 설비 아래 초록 진행바, 멈춘 설비 오른쪽 위 아이콘(빈 상자·빨간 화살표·번개·?·물방울·렌치). 0.8배 미만으로 축소하면 아이콘이 숨어요.
- □ 시계 09:00 → 18:00(실제 20분, ×8 속도로 약 2분 30초) → '하루 끝' 창 → [다음 날] 09:00.

## 8. 직원

- □ 디버그 메뉴 '고용: …' → 정문 안쪽에서 생겨요. 직원 탭 = 작은 정보창(이름·상태·오늘 처리 수).
- □ 배달 직원: 출하대 → 정문 → 사라짐 → 다시 들어옴. 2명이면 더 빨리 배달 수가 올라가요.
- □ 정비 직원: [구역 지정] → 꾹-끌기로 구역, 디버그 '무작위 고장' → 구역 안 고장 설비로 가서 8초 수리.
- □ 길을 설비로 막으면 '길이 막혔어요', 치우면 다시 가요.

## 9. 성능

- □ 메뉴 → 디버그 → F3 디버그 오버레이를 켜고, 큰 공장(예시 불러오기 + 설비를 많이 깔기)에서 50fps 이상인지.
- □ 1분마다 '자동 저장' 알림이 떠도 끊기지 않아요.
