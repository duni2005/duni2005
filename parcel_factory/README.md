# 택배 공장 샌드박스 (Godot 4.3+)

크리에이티브 모드처럼 모든 설비를 마음대로 깔고 공장이 도는지 시험하는 프로젝트예요.
돈·등급·생물은 아직 없고, 공장 요소 + 플레이어·인벤토리까지 있어요.

## 여는 법
1. Godot 4.3 이상을 준비해요 (안드로이드는 Play 스토어의 **Godot Editor 4**).
2. 압축을 풀고 Godot 프로젝트 관리자에서 `project.godot`을 가져와(Import) 실행해요.
3. 처음 켜면 빈 **큰방**(쓰레기 더미·물 샘 + 지급 설비)에서 시작해요. 저장 파일(`user://save.json`)이 있으면 그 공장으로 이어서 시작해요.
   예시 공장 4개는 **예시 불러오기** 버튼으로 큰방 안에 깔아요.

## 큰방 (`scripts/map/room.gd`)
- 안쪽 50×40칸(상수 `W`, `H`), 둘레 1칸 벽. 칸은 32px(16px 도트 × 2).
- 왼쪽 끝 **엄청난 쓰레기 더미**(4×40, 기본 혼합 Lv1): 오른쪽 면의 **노란 점선 출구 자리 4곳**에만 출구를 붙일 수 있어요. 더미 앞에서 탭 → **손으로 뒤지기**(3초)로 3~5개가 가방에 들어와요.
- 오른쪽 **정문**(10칸 폭)과 문 앞 2칸 **통로**(노랑·검정 사선)는 설치 금지.
- 위·아래 가운데 **복도** 입구(5칸 폭)는 모습만 있고 막혀 있어요.
- 방 밖은 어둡게, 확장 예정 구간 A~F는 점선으로만 보여요.
- 지급 설비(정문 근처): 작업 컴퓨터, 출하대, 바이오 발전기 + '작업대 자리'(설비가 아직 없어 비워 둠). 오른쪽 위 구석에 물 샘.
- **메뉴 → 크리에이티브(디버그)** 를 켜면 지형 규칙 없이 방 밖·벽에도 설치하고 더미도 지울 수 있어요.
- **비우기**는 지형 설비(더미·물 샘)만 남기고 지워요.

## 조작
플레이어(주황 모자 직원)가 큰방을 걸어 다니며 **주변에서** 일해요. 카메라는 플레이어를 따라가요.

| 동작 | PC | 모바일 |
|---|---|---|
| 걷기 (2칸/초) | WASD · 방향키 | 왼쪽 아래 조이스틱 |
| 달리기 (3칸/초) | Shift | 조이스틱 끝까지 |
| 상호작용 (바라보는 대상) | F | 오른쪽 아래 버튼 |
| 특정 설비와 상호작용 | 손 닿는 설비를 마우스 왼쪽 | 손 닿는 설비를 탭 |
| 핫바 고르기 (손에 들기, 같은 칸 다시 = 맨손) | 1~9 · 휠 | 핫바 탭 |
| 가방 | E · Tab | 핫바 오른쪽 '가방' 버튼 · 핫바를 위로 쓸기 |
| 확대·축소 | Ctrl+휠 | 두 손가락 |
| 취소 (가방·메뉴 닫기 → 하던 일·든 것 내려놓기 → 도구 취소) | Esc · 마우스 오른쪽 | — |

- **대상**: 플레이어 중심 2.5칸 안에서 바라보는 방향에 가장 가까운 설비·레일·더미. 흰 꺾쇠 테두리와 말풍선(손 = 줍기·꺼내기·뒤지기, 톱니 = 정보, 상자 = 넣기)이 떠요.
- **탭(짧게)**: 쓰레기 더미 뒤지기(3초, 3~5개) · 레일 위 물건 줍기 · 설비 결과물 꺼내기 · 그 밖엔 정보 창.
  핫바에서 물건을 골라 **손에 들면** 탭 = 대상에 1개 넣기.
- **꾹(길게)**: 설비 철거(1초 게이지 → `[설비] 이름` 아이템과 안에 든 물건이 가방으로, 넘치면 바닥에) · 들고 있으면 다 넣기 · 대상이 없으면 휘두르기.
- **설치·철거 도구**는 플레이어에게서 6칸 안에서만 돼요(크리에이티브면 어디든). 철거 도구로 지운 설비도 가방으로 돌아와요.
- 벽·설비에는 막히고, 레일 계열(레일·분류기·분배기 등)·전선·파이프 위는 걸어 다녀요.
- 아래 팔레트·위 도구 막대·**회전**·**층 보기**·**예시 불러오기**·**비우기**·**메뉴**는 그대로예요. 터치 조작은 터치 화면에서 자동으로 보이고, 메뉴에서 켜고 끌 수 있어요.
- **F3**: 디버그 오버레이 (FPS, 틱/초, 설비 수, 레일 위 물건 수, 전력망별 공급/수요).

## 인벤토리 · 바닥 아이템
- **핫바 9칸 + 가방 27칸** (`Inventory.HOTBAR`, `Inventory.BAG`). 쌓기: 일반 50 · 설비 20 · 레일·전선·파이프 100, 내용물이 있는 박스·택배는 1칸 1개.
- 설비도 아이템이에요: `[설비] 포장기`처럼. 설비 제작대의 `[설비] 레일 Mk1 ×4`는 `[설비] 레일 Mk1` 4개로 나와요.
- 가방 안: **끌어다 놓기** = 옮기기(같은 물건이면 합치기) · **두 칸을 차례로 탭** = 바꾸기 · **길게 누르기/오른쪽 클릭** = 반 나누기 · **Shift+클릭** = 핫바↔가방 빠른 이동 · **창 밖으로 끌어 놓기** = 플레이어 앞에 버리기.
- 바닥 아이템: 같은 칸·같은 아이템은 한 무더기. 플레이어 1칸 안에 들어오면 끌려와 주워져요(가방이 가득이면 그대로). 레일·설비 위에도 놓이지만 시뮬레이션과 이동에는 영향이 없어요. 버린 물건은 1.5초 동안 다시 줍지 않아요.
- 결과물 꺼내기·더미 뒤지기·철거에서 가방에 안 들어가는 건 그 자리 바닥에 떨어져요.
- **메뉴 → 크리에이티브 보관함(디버그)** 을 켜면 가방 창에 '크리에이티브 보관함' 탭이 생겨요. 누르면 그 물건 한 묶음.
- 새 게임 시작 지급품: 나무 판자 20 · 나사 40 · [설비] 레일 Mk1 100 · [설비] 전선 50 · 박스 테이프 20 · 작은 택배 박스 40.

## 그래픽 (탑뷰 도트)
- 도트 16×16, 화면 2배(칸 32px). 월드는 Nearest 필터, 프로젝트는 픽셀 스냅 켬.
- 색은 **고정 팔레트 32색**(`assets/palette.gd`, 견본 `assets/palette.png`)만 써요. 누런 벽지·깔끔한 어두운 바닥 타일·회색 설비·주황 택배 박스. 천장 형광등 빛은 더하기 합성 원형 빛 몇 개로 표현해요.
- 그리는 방식: 바닥·벽 = TileMapLayer, 설비 = 설비마다 Sprite2D 하나(+1도트 그림자), 레일 위 물건 = 한 노드 `_draw`로 일괄.
- 레일은 뒤가 비고 한쪽 옆에서만 받으면 자동으로 꺾인 모양이 돼요. 막힌 레일은 벨트가 멈춰요.
- 설비는 가동 중일 때만 움직이고(멈춤 = 0번 프레임), 왼쪽 위 등이 전력 상태(초록·노랑·빨강), 오른쪽 아래 아이콘이 만드는 물건이에요.
- 전선·파이프는 바닥 위 얇은 선, **층 보기**를 켜면 설비 위에 진하게.

### 그림 바꿔 끼우기
1. 임시 도트는 `tools/gen_assets.tscn`이 `assets/gen/*.png`로 구워 둬요:
   `godot --headless --path . res://tools/gen_assets.tscn`
2. 직접 그린 그림은 **같은 이름**으로 `assets/sprites/`에 넣으면 그걸 먼저 써요 (생성 도구가 덮어쓰지 않아요).
3. 시트 배치(프레임 수·줄 순서)는 `assets/sprite_gen.gd` 맨 위 설명, 아이템 아이콘 순서는 `assets/gen/items_index.txt`.

## 저장
`user://save.json`에 설비(위치·방향·레시피·설정), 전선, 파이프, 물 샘, 크리에이티브 여부를 저장해요. 플레이어(위치·HP·핫바·인벤토리)와 바닥 아이템도 저장해요. 레일 위·창고 안 물건은 아직 저장하지 않아요.
저장 형식 버전 2(큰방)·3(바닥 아이템)을 읽어요. 그보다 오래된 저장(무한 격자 버전)은 무시하고 새 큰방으로 시작해요.

## 테스트
```
godot --headless --path . --import          # 처음 한 번 (class_name 목록 만들기)
godot --headless --path . res://tests/sim_test.tscn
godot --headless --path . res://tests/player_test.tscn
```
레일 Mk1 1분 = 60개, 분해기 나뭇가지→종이 분당 60, 전력 50% 부족 시 속도 절반, 큰방 설치 규칙·크리에이티브, 쓰레기 더미 출구 자리·손으로 뒤지기, 큰방 안 예시 공장 4개, 인벤토리 쌓기·정리, 바닥 아이템, 저장→불러오기(바닥 아이템·인벤토리 포함), 손으로 줍기·넣기·꺼내기·철거를 확인하고 결과를 출력해요 (실패가 있으면 종료 코드 1).
`player_test`는 실제 씬에서 걷기·달리기 속도, 설비·벽 충돌, 더미 뒤지기, 핫바로 넣기·꺼내기, 철거, 휘두르기, 버렸다가 다시 줍기, 게임 저장→불러오기(인벤토리·핫바·바닥 아이템·위치)를 확인해요. 테스트용 저장 파일을 따로 써서 진짜 저장은 건드리지 않아요.

## 규칙 요약
- 고정 틱 0.05초라 분당 수치가 기획서와 같아요 (레일 Mk1 = 60개/분).
- 설비는 **레일이 자기를 향하면** 그 물건을 받아요. 결과물은 **둘레에서 바깥을 향한 레일**로 자동으로 나가고, **출구**를 붙여 꺼낼 수도 있어요.
- 전력: 전선 위에 걸친 설비만 전력을 받아요. 충족률(공급 ÷ 수요, 최저 10%)만큼 느려져요.
  설비 왼쪽 위 점: 초록 = 정상, 노랑 = 부족, 빨강 = 없음.
- 물: 물 샘 위 펌프 → 파이프 → 주입기 (레일 위에서 양동이·페트병을 채워요).
- 택배 라인: 작업 컴퓨터(요청서) → 요청 결합기(빈 박스 + 요청서) → 요청 감지기(옆에서 물건 공급) → 완료 판정기(다 찬 박스는 오른쪽) → 포장기(테이프 2) → 출하대.
- 크리에이티브 전용: 물건 더미(종류·Lv 변경), 무한 공급기, 소각기, 물 샘.

## 폴더
- `data/` 아이템·레시피·설비 수치 (JSON). 밸런스는 여기만 고치면 돼요.
- `scripts/sim/` 시뮬레이션 (설비마다 파일 하나).
- `scripts/view/` 화면 그리기와 UI (`debug_overlay.gd` 디버그 오버레이, `hud.gd`).
- `tests/` 시뮬레이션 테스트.
- `scripts/demo.gd` 예시 공장 (`ORIGIN` 기준으로 큰방 안에 깔려요).
- `scripts/map/` 지형 (큰방).
- `assets/` 팔레트·도트 생성기(`sprite_gen.gd`)·텍스처 창고(`art.gd`)·구운 PNG(`gen/`)·교체용 그림(`sprites/`).
- `scripts/view/` 화면: `world_view.gd`(층 조립·타일), `building_layer.gd`(설비 스프라이트), `item_layer.gd`(레일 위 물건), `marker_layer.gd`(전력 등·아이콘·고스트), `room_overlay.gd`, `line_layer.gd`.
- `scripts/player/` 플레이어(`player.gd`), 충돌(`world_collision.gd`), 대상 표시(`target_marker.gd`).
- `scripts/sim/inventory.gd` 인벤토리(핫바+가방), `floor_items.gd` 바닥 아이템, `item_io.gd` 물건 저장.
- `scenes/inventory_panel.tscn` 인벤토리 창 (가운데 / 가운데 오른쪽 두 자리에서 재사용), `scripts/view/hotbar.gd`·`inv_slot.gd`·`drop_layer.gd`·`item_drop.gd`.
- `tools/` 에셋 굽기 도구.

## 참고
- Godot 4.3 stable에서 실행·테스트했어요. 오류가 뜨면 **출력(Output) 창의 빨간 줄**을 그대로 보내 주세요.
- 내보내기(Export)할 때는 내보내기 설정의 '리소스 외 파일 포함'에 `*.json`을 넣어야 데이터가 들어가요.
