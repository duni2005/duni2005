# 택배 공장 샌드박스 (Godot 4.3+)

크리에이티브 모드처럼 모든 설비를 마음대로 깔고 공장이 도는지 시험하는 프로젝트예요.
돈·등급·생물은 아직 없고, 공장 요소 + 플레이어·인벤토리까지 있어요.

## 여는 법
1. Godot 4.3 이상을 준비해요 (안드로이드는 Play 스토어의 **Godot Editor 4**).
2. 압축을 풀고 Godot 프로젝트 관리자에서 `project.godot`을 가져와(Import) 실행해요.
3. 처음 켜면 빈 **큰방**(쓰레기 더미·물 샘 + 지급 설비)에서 시작해요. 저장 파일(`user://save.json`)이 있으면 그 공장으로 이어서 시작해요.
   예시 공장 4개는 **예시 불러오기** 버튼으로 큰방 안에 깔아요.

## 큰방 (`scripts/map/room.gd`)
- 안쪽 50×40칸(상수 `W`, `H`), 둘레 1칸 벽. 칸은 32px(16px 도트 × 2).
- 왼쪽 끝 **엄청난 쓰레기 더미**(4×40, 기본 혼합 Lv1): 오른쪽 면의 **노란 점선 출구 자리 4곳**에만 출구를 붙일 수 있어요. 더미 앞에서 탭 → **손으로 뒤지기**(3초)로 3~5개가 가방에 들어와요.
- 오른쪽 **정문**(10칸 폭)과 문 앞 2칸 **통로**(노랑·검정 사선)는 설치 금지.
- 위·아래 가운데 **복도** 입구(5칸 폭)는 모습만 있고 막혀 있어요.
- 방 밖은 어둡게, 확장 예정 구간 A~F는 점선으로만 보여요.
- 지급 설비(정문 근처): 작업 컴퓨터, 출하대, 바이오 발전기 + '작업대 자리'(설비가 아직 없어 비워 둠). 오른쪽 위 구석에 물 샘.
- **메뉴 → 크리에이티브(디버그)** 를 켜면 지형 규칙 없이 방 밖·벽에도 설치하고 더미도 지울 수 있어요.
- **비우기**는 지형 설비(더미·물 샘)만 남기고 지워요.

## 조작 · 화면 (모바일 가로 화면 기준, PC도 같은 화면)
> 조작 전체 표는 [`docs/CONTROLS.md`](docs/CONTROLS.md)에 있어요 (조작이 바뀌면 같이 고쳐요).

| 자리 | 내용 |
|---|---|
| 왼쪽 위 | 지금 상호작용 대상 이름 · 짧은 상태 (예: `분해기 · 작업 중 63%`) |
| 오른쪽 위 | 시계(09:00~18:00, 하루 = 실제 20분) + 오늘 배달 수(정상·오배송) · 멈춤 · 속도 · 메뉴, 그 아래 `철거 모드` 같은 모드 글씨 |
| 왼쪽 아래 | 떠 있는 조이스틱: 화면 왼쪽 35% × 아래 60% 안을 누르면 그 자리에 생겨요 (데드존 15%, 끝까지 = 달리기) |
| 가운데 아래 | HP 바(+스테미나 자리) · 핫바 9칸 + 가방 버튼 |
| 오른쪽 아래 | 상호작용 버튼(큰 원) · 회전 버튼(설비를 들었을 때만) · 그 위 모드 묶음 [일반][이동][철거] |
| 가장자리 | 이동 모드 = 파란 테두리, 철거 모드 = 붉은 테두리 |

- 상호작용 버튼 아이콘: 일반 모드 — 맨손 주먹 / 아이템 손 / 설비 망치(설치), 이동 모드 — 십자 화살표, 철거 모드 — 빨간 쇠지렛대.
- 모드는 `PlayMode` 한 곳에서 관리해요. 이동·철거 동작과 범위 선택은 `scripts/player/edit_controller.gd` (아래 "이동 · 철거 · 범위 선택"). 핫바에서 설비를 고르거나 Esc를 누르면 일반 모드.
- 조이스틱 영역 밖의 월드 화면(일반 모드): 3칸 안 설비를 탭 = 정보창, 3칸 밖이면 '가까이 가야 해요'와 그 설비 테두리 깜빡임.
- 터치가 들어오면 터치 UI(조이스틱)를, 키보드·마우스를 쓰면 조이스틱을 숨겨요 (메뉴 → 설정 → 조작에서 고정도 가능).
- 메뉴: **저장**(저장 · 불러오기) / **설정**(UI 크기 80~150% · 조작 방식) / **디버그**(F3 오버레이 · 크리에이티브 · 크리에이티브 보관함 · 설치 팔레트 · 층 보기 · 예시 불러오기 · 비우기). 설정은 `user://settings.cfg`.
- 노치(안전 영역)를 피하고, 모든 UI는 화면 가장자리에 붙어 있어요. 버튼은 최소 64px.

| 동작 | PC | 모바일 |
|---|---|---|
| 걷기 · 달리기 | WASD · Shift | 조이스틱 · 끝까지 밀기 |
| 상호작용 | F · 마우스 왼쪽 (마우스를 올린 칸이 대상) | 상호작용 버튼 (바라보는 대상) · 손 닿는 설비 탭 |
| 핫바 | 1~9 | 핫바 탭 |
| 가방 | E · Tab | 가방 버튼 · 핫바를 위로 쓸기 |
| 회전 | R | 회전 버튼 |
| 모드 | Z 일반 · X 이동 · C 철거 | 모드 묶음 버튼 |
| 범위 선택 · 선택 철거 | 빈 곳 왼쪽 버튼 꾹-끌기 (Shift = 더하기) · Delete | 빈 칸 꾹-끌기 · 선택 바 |
| 확대·축소 (0.5~3배, 저장) | 휠 | 두 손가락 |
| 둘러보기 | 마우스 가운데 버튼 끌기 | 조이스틱 영역 밖 월드를 누르자마자 끌기 |
| 취소 (가방·메뉴 닫기 → 일반 모드 → 하던 일·든 것 내려놓기) | Esc · 마우스 오른쪽 | — |

- **탭(짧게)**: 설비 정보창 열기 (들고 있어도 같아요). 레일·출구·분배기 같은 단순 벨트 장치는 위 물건 줍기, 쓰레기 더미는 뒤지기(3초, 3~5개).
- **꾹(길게, 0.35초)**: 설비 아이템을 들고 있으면 설치 시작(아래 "설치") · 들고 있는 아이템 빠른 넣기(넣을 수 있는 만큼) · 맨손이면 휘두르기. 철거는 철거 모드 또는 정보창의 [철거(꾹)] 버튼.
- 대상은 플레이어 중심 3칸(`Player.REACH` = INFO_RANGE) 안. 흰 꺾쇠 테두리와 말풍선(손 = 줍기·뒤지기, 톱니 = 정보창, 상자 = 들고 꾹 넣기)이 떠요. 설치 팔레트로 놓는 건 플레이어 6칸 안(크리에이티브면 어디든).

## 공장 상태 한눈에 (`scripts/view/status_icons.gd`)
- 설비 아래 얇은 초록 진행바: 가동 중일 때만 (레시피·포장·주입 진행률), 멈추면 숨겨요.
- 설비 오른쪽 위 상태 아이콘(8×8): 빈 상자 = 재료 부족 · 빨간 화살표 = 출력 막힘 · 번개 빨강/노랑 = 전력 없음/부족 · ? = 레시피 없음 · 물방울 = 물 부족. 화면 확대 0.8배 미만이면 숨겨요. 정보창 상태 줄도 같은 판단·아이콘(`StatusIcons.classify`).
- 하루: 18:00이 되면 '하루 끝' 창(오늘 배달 수)과 함께 시뮬레이션이 멈추고, [다음 날]을 누르면 다음 날 09:00부터 (밤 시스템은 아직 없어요). 날짜·시각·오늘 배달 수는 저장돼요.

## 카메라 · 조작감
- 카메라: 데드존 1칸 따라가기, 달리면 앞을 1.5칸, 둘러보기는 떼고 1.5초 뒤 복귀, 설치·이동·범위 선택 중 화면 가장자리 15%에서 천천히 이동, 화면 픽셀 반올림(떨림 없음). 확대는 `user://settings.cfg`에 저장 (`main.gd`의 `update_camera`).
- 조이스틱 제곱 곡선, 코너 보정(0.4칸), 대상 고정 0.15초, 손가락 위 꾹 게이지, 미리보기 칸 이동 '틱'·진동, 모든 버튼 누름 효과(95%·밝게).
- 효과음 자리: `assets/sfx/` (`button`·`place`·`break`·`tick`, 없으면 코드 소리나 무음 — `assets/sfx/README.md`).
- 연속 설치: 메뉴 → 설정 → 연속 설치 (기본 끔: 버튼을 끌어 조준하는 것과 같은 손동작이라서).
- 손동작끼리 겹치는 곳과 규칙은 `docs/CONTROLS.md`의 "손동작 구분".

## 설치 (`scripts/player/build_controller.gd`)
- 일반 모드에서 핫바에 설비 아이템을 들고 **상호작용 버튼을 꾹** → 설치 모드. 반투명 미리보기가 플레이어 앞 칸에 떠요.
- 누른 채 **끌면** 미리보기가 움직여요(40px = 1칸). 설치 중 **월드를 터치**하면 그 칸으로 바로 옮겨요.
- **떼면 설치**. 끈 뒤 버튼 가운데(빨간 X)로 되돌아와 떼면 **취소**.
- 초록 테두리 = 설치 가능 / 빨강 + 이유 = 막힘(벽 · 다른 설비 · 통로 · 거리 · 개수 부족). 설치 거리는 플레이어 8칸(`Main.BUILD_RANGE`, 9단계 철거·이동도 같은 값).
- 회전: 회전 버튼 · R · 두 번째 손가락 탭. 설비 종류마다 마지막 방향을 기억해요. 레시피가 정해진 설비는 분당 입출력을 같이 보여 줘요.
- 설치하면 인벤토리에서 1개 빠지고 '착' 소리 · 진동 · 먼지가 나요.
- **레일 두 점 설치**: 첫 설치 = A 칸에 놓고 깃발 고정 → 다음 설치 = B까지 일자/ㄱ자로 이어요(꺾는 순서는 끈 방향, 회전 버튼으로 바꾸기). 방향·곡선은 자동, 같은 레일은 방향만 덮어써요. 하나라도 막히면 경로 전체가 빨강, 모자라면 "레일 N개 필요 / M개 있음". 설치 뒤 B가 새 A, B = A면 그 칸만 놓고 A 해제, 취소하면 A 해제.
- **파이프·전선**도 두 점 방식(방향 없음). 설비 밑으로 지나가고 벽만 막아요. 들면 층 보기가 자동으로 켜져요.
- **PC**: 미리보기가 마우스를 따라가요. 왼쪽 클릭 = 설치(레일은 두 번 클릭 A→B), 오른쪽 클릭 = 취소.

## 이동 · 철거 · 범위 선택 (`scripts/player/edit_controller.gd`)
- 월드 누르기: 0.35초 전에 12px 넘게 움직이면 '끌기'(10단계 둘러보기 자리), 아니면 짧게 = 탭, 길게 = 꾹.
- **철거 모드**: 설비 꾹 → 원형 게이지 0.6초 → 철거(내용물 + 제작 재료가 그 자리에, 파편·소리). 떼면 취소. 탭 = '꾹 눌러서 철거' 안내. 상호작용 버튼 꾹 = 지금 대상.
- **이동 모드**: 설비 꾹 → 들어서 따라오는 미리보기(원래 자리 점선, 그동안 설비는 멈춤) → 놓으면 이동(내용물·레시피·설정·방향 유지, 레일 위 물건도 같이). 막히거나 거리 밖이면 0.15초 만에 제자리로. 회전 버튼·R·두 번째 손가락 탭으로 회전. 상호작용 버튼 꾹 → 버튼을 끌어 조준(가운데 X = 취소). 정보창 [이동]은 그 설비를 골라 이동 모드로.
- **범위 선택**(모든 모드): 빈 칸 꾹 → 끌어서 사각형 → 놓기. 노란 테두리 + 화면 위 '설비 N개 선택됨' [이동][철거(꾹)][해제]. 선택된 설비를 꾹 = 묶음 철거(게이지 옆 'N개 철거', 20개 넘으면 1.2초)·묶음 이동(평행 이동만). 선택 밖 탭 = 해제. 전선·파이프는 층 보기를 켰을 때만 들어가요.
- 거리 8칸(`Main.BUILD_RANGE`)은 잡은 설비 기준. 지급 설비·지형은 철거·이동 불가.
- 공장 쪽: `factory.move_check` / `move_buildings(list, offset, rot)`(전부 될 때만 한 번에) / `deconstruct_many(list)` / `set_held`. 연결·전력망·물망·창고 묶음은 다음 틱에 한 번만 다시 계산해요.

## 설비 정보창 (`scripts/view/info_panel.gd`)
- 화면 가운데 왼쪽(폭 40%)에 정보창, 가운데 오른쪽에 인벤토리가 '주고받기' 모드로 함께 열려요. 열린 동안 아래 HUD(핫바·조이스틱·버튼)는 숨고 플레이어는 멈춰요. 시뮬레이션은 계속 돌고 창은 0.1초마다 갱신.
- 내용: 아이콘·이름·분류·크기·전력 / 설명 / **상태** 탭(색 점 + 아이콘 + 짧은 글, 입력 칸 → 진행 화살표 → 출력 칸, 진행·남은 시간, 전력, 분당 입출력, 종류별 정보) / **설정** 탭(종류별, 레시피는 아이콘 격자 팝업) / [이동] · [철거(꾹 0.6초)]. 마지막 탭은 설비 종류별로 기억해요.
- 주고받기: 정보창 칸 탭 = 1개를 인벤토리로, 꾹(0.35초, 원형 게이지)·Shift+클릭 = 전부, 오른쪽 클릭 = 반. 인벤토리 칸 탭 = 1개를 설비로(어느 칸인지는 설비가 정해요), 꾹·Shift+클릭 = 넣을 수 있는 만큼, 오른쪽 클릭 = 반. 넣을 수 없는 아이템은 흐리게(40%). 끌기는 여전히 가방 정리.
- 옮기면 아이템이 날아가는 연출 + 개수 튕김, 실패하면 칸이 흔들리고 이유('넣을 수 없어요' · '가득 찼어요' · '인벤토리가 가득 찼어요')가 떠요. 못 옮긴 건 그대로 남아요.
- 레시피를 바꾸면 새 레시피에 안 쓰이는 재료는 인벤토리로(넘치면 바닥에).
- 닫기: X · 두 창 바깥 탭 · Esc · E · 설비가 사라졌을 때 · PC는 WASD.
- 철거: 설비 안의 모든 물건 + 설비 제작대 레시피 재료 100%가 그 자리 바닥에 쏟아져요. 레일·전선·파이프처럼 한 번에 여러 개 만드는 것은 설비 아이템 1개, 제작법이 없는 크리에이티브 설비도 설비 아이템. 창고 블록은 줄어든 용량만큼 넘치는 것만. 지급 설비(작업 컴퓨터·출하대·바이오 발전기)와 지형(쓰레기 더미·물 샘)은 철거할 수 없어요(버튼 회색).
- [이동]: 창을 닫고 이동 모드로 바꿔요 (실제로 들어 옮기기는 9단계).
- 벽·설비에는 막히고, 레일 계열·전선·파이프 위는 걸어 다녀요.

## 인벤토리 · 바닥 아이템
- **핫바 9칸 + 가방 27칸** (`Inventory.HOTBAR`, `Inventory.BAG`). 쌓기: 일반 50 · 설비 20 · 레일·전선·파이프 100, 내용물이 있는 박스·택배는 1칸 1개.
- 설비도 아이템이에요: `[설비] 포장기`처럼. 설비 제작대의 `[설비] 레일 Mk1 ×4`는 `[설비] 레일 Mk1` 4개로 나와요.
- 가방 안: **끌어다 놓기** = 옮기기(같은 물건이면 합치기) · **두 칸을 차례로 탭** = 바꾸기 · **길게 누르기/오른쪽 클릭** = 반 나누기 · **Shift+클릭** = 핫바↔가방 빠른 이동 · **창 밖으로 끌어 놓기** = 플레이어 앞에 버리기.
- 바닥 아이템: 같은 칸·같은 아이템은 한 무더기. 플레이어 1칸 안에 들어오면 끌려와 주워져요(가방이 가득이면 그대로). 레일·설비 위에도 놓이지만 시뮬레이션과 이동에는 영향이 없어요. 버린 물건은 1.5초 동안 다시 줍지 않아요.
- 더미 뒤지기·레시피 바꾸기에서 가방에 안 들어가는 건 그 자리 바닥에 떨어져요.
- **메뉴 → 크리에이티브 보관함(디버그)** 을 켜면 가방 창에 '크리에이티브 보관함' 탭이 생겨요. 누르면 그 물건 한 묶음.
- 새 게임 시작 지급품: 나무 판자 20 · 나사 40 · [설비] 레일 Mk1 100 · [설비] 전선 50 · 박스 테이프 20 · 작은 택배 박스 40.

## 그래픽 (탑뷰 도트)
- 도트 16×16, 화면 2배(칸 32px). 월드는 Nearest 필터, 프로젝트는 픽셀 스냅 켬.
- 색은 **고정 팔레트 32색**(`assets/palette.gd`, 견본 `assets/palette.png`)만 써요. 누런 벽지·깔끔한 어두운 바닥 타일·회색 설비·주황 택배 박스. 천장 형광등 빛은 더하기 합성 원형 빛 몇 개로 표현해요.
- 그리는 방식: 바닥·벽 = TileMapLayer, 설비 = 설비마다 Sprite2D 하나(+1도트 그림자), 레일 위 물건 = 한 노드 `_draw`로 일괄.
- 레일은 뒤가 비고 한쪽 옆에서만 받으면 자동으로 꺾인 모양이 돼요. 막힌 레일은 벨트가 멈춰요.
- 설비는 가동 중일 때만 움직이고(멈춤 = 0번 프레임), 왼쪽 위 등이 전력 상태(초록·노랑·빨강), 오른쪽 아래 아이콘이 만드는 물건이에요.
- 전선·파이프는 바닥 위 얇은 선, **층 보기**를 켜면 설비 위에 진하게.

### 그림 바꿔 끼우기
1. 임시 도트는 `tools/gen_assets.tscn`이 `assets/gen/*.png`로 구워 둬요:
   `godot --headless --path . res://tools/gen_assets.tscn`
2. 직접 그린 그림은 **같은 이름**으로 `assets/sprites/`에 넣으면 그걸 먼저 써요 (생성 도구가 덮어쓰지 않아요).
3. 시트 배치(프레임 수·줄 순서)는 `assets/sprite_gen.gd` 맨 위 설명, 아이템 아이콘 순서는 `assets/gen/items_index.txt`.

## 저장
`user://save.json`에 설비(위치·방향·레시피·설정), 전선, 파이프, 물 샘, 크리에이티브 여부를 저장해요. 플레이어(위치·HP·핫바·인벤토리)와 바닥 아이템도 저장해요. 레일 위·창고 안 물건은 아직 저장하지 않아요.
저장 형식 버전 2(큰방)·3(바닥 아이템)을 읽어요. 그보다 오래된 저장(무한 격자 버전)은 무시하고 새 큰방으로 시작해요.

## 규칙 요약
- 고정 틱 0.05초라 분당 수치가 기획서와 같아요 (레일 Mk1 = 60개/분).
- 설비는 **레일이 자기를 향하면** 그 물건을 받아요. 결과물은 **둘레에서 바깥을 향한 레일**로 자동으로 나가고, **출구**를 붙여 꺼낼 수도 있어요.
- 전력: 전선 위에 걸친 설비만 전력을 받아요. 충족률(공급 ÷ 수요, 최저 10%)만큼 느려져요.
  설비 왼쪽 위 점: 초록 = 정상, 노랑 = 부족, 빨강 = 없음.
- 물: 물 샘 위 펌프 → 파이프 → 주입기 (레일 위에서 양동이·페트병을 채워요).
- 택배 라인: 작업 컴퓨터(요청서) → 요청 결합기(빈 박스 + 요청서) → 요청 감지기(옆에서 물건 공급) → 완료 판정기(다 찬 박스는 오른쪽) → 포장기(테이프 2) → 출하대.
- 크리에이티브 전용: 물건 더미(종류·Lv 변경), 무한 공급기, 소각기, 물 샘.

- `assets/` 팔레트·도트 생성기(`sprite_gen.gd`)·텍스처 창고(`art.gd`)·구운 PNG(`gen/`)·교체용 그림(`sprites/`).
- `scripts/view/` 화면: `world_view.gd`(층 조립·타일), `building_layer.gd`(설비 스프라이트), `item_layer.gd`(레일 위 물건), `marker_layer.gd`(전력 등·아이콘·고스트), `room_overlay.gd`, `line_layer.gd`.

- `scenes/inventory_panel.tscn` 인벤토리 창 (가운데 / 정보창 옆 가운데 오른쪽 두 자리에서 재사용), `scripts/view/hotbar.gd`·`inv_slot.gd`·`drop_layer.gd`·`item_drop.gd`.

- `tools/` 에셋 굽기 도구.
