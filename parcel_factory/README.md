# 택배 공장 샌드박스 (Godot 4.3+)

크리에이티브 모드처럼 모든 설비를 마음대로 깔고 공장이 도는지 시험하는 프로젝트예요.
돈·등급·가방·생물은 아직 없고, **공장 요소만** 있어요.

## 여는 법
1. Godot 4.3 이상을 준비해요 (안드로이드는 Play 스토어의 **Godot Editor 4**).
2. 압축을 풀고 Godot 프로젝트 관리자에서 `project.godot`을 가져와(Import) 실행해요.
3. 처음 켜면 **예시 공장 4개**가 깔려서 바로 돌아가요. 저장 파일(`user://save.json`)이 있으면 그 공장으로 시작해요.

## 조작
| 동작 | 보기 | 설치 | 철거 |
|---|---|---|---|
| 탭 | 설비 선택 → 오른쪽 정보 패널 | 놓기 | 지우기 |
| 한 손가락 끌기 | 화면 이동 | 레일·전선·파이프·물 샘은 끌어서 깔기, 나머지는 화면 이동 | 끌면서 지우기 |
| 두 손가락 | 확대·축소, 이동 | 같음 | 같음 |

- **회전**: 설치 방향을 돌려요. 보기에서 1칸 설비를 고른 뒤 누르면 그 설비가 돌아가요.
- **층 보기**: 전선(노랑)·파이프(파랑) 표시를 켜고 꺼요.
- **멈춤 / ×1~×8**: 시뮬레이션 속도.
- **예시 / 비우기**: 예시 공장을 다시 깔거나 전부 지워요.
- 철거는 설비 → 전선 → 파이프 → 물 샘 순서로 한 칸에서 하나씩 지워요.
- **F3**: 디버그 오버레이 (FPS, 틱/초, 설비 수, 레일 위 물건 수, 전력망별 공급/수요).
- **메뉴**: 저장 · 불러오기 · 팔레트 접기.

### 키보드·마우스 (InputMap 액션, `project.godot`의 [input])
| 액션 | 키 | 하는 일 |
|---|---|---|
| move_up/down/left/right | WASD · 방향키 | 화면 이동 |
| interact | F · 마우스 왼쪽 | 탭과 같음 (F는 마우스가 가리키는 칸) |
| cancel | Esc · 마우스 오른쪽 | 메뉴 닫기 → 설치·철거 취소 → 정보 패널 닫기 |
| rotate | R | 회전 |
| hotbar_1~9 | 1~9 | 지금 팔레트 분류의 n번째 설비 고르기 (버튼 앞 숫자) |
| inventory | E · Tab | 아래 팔레트 접기/펴기 |
| zoom_in / zoom_out | 휠 | 확대·축소 |
| debug | F3 | 디버그 오버레이 |
| save_game | Ctrl+S | 저장 |

## 저장
`user://save.json`에 설비(위치·방향·레시피·설정), 전선, 파이프, 물 샘을 저장해요. 물건 내용물(레일 위·창고 안)은 아직 저장하지 않아요.

## 테스트
```
godot --headless --path . --import          # 처음 한 번 (class_name 목록 만들기)
godot --headless --path . res://tests/sim_test.tscn
```
레일 Mk1 1분 = 60개, 분해기 나뭇가지→종이 분당 60, 전력 50% 부족 시 속도 절반, 예시 공장 4개, 저장→불러오기를 확인하고 결과를 출력해요 (실패가 있으면 종료 코드 1).

## 규칙 요약
- 고정 틱 0.05초라 분당 수치가 기획서와 같아요 (레일 Mk1 = 60개/분).
- 설비는 **레일이 자기를 향하면** 그 물건을 받아요. 결과물은 **둘레에서 바깥을 향한 레일**로 자동으로 나가고, **출구**를 붙여 꺼낼 수도 있어요.
- 전력: 전선 위에 걸친 설비만 전력을 받아요. 충족률(공급 ÷ 수요, 최저 10%)만큼 느려져요.
  설비 왼쪽 위 점: 초록 = 정상, 노랑 = 부족, 빨강 = 없음.
- 물: 물 샘 위 펌프 → 파이프 → 주입기 (레일 위에서 양동이·페트병을 채워요).
- 택배 라인: 작업 컴퓨터(요청서) → 요청 결합기(빈 박스 + 요청서) → 요청 감지기(옆에서 물건 공급) → 완료 판정기(다 찬 박스는 오른쪽) → 포장기(테이프 2) → 출하대.
- 크리에이티브 전용: 물건 더미(종류·Lv 변경), 무한 공급기, 소각기, 물 샘.

## 폴더
- `data/` 아이템·레시피·설비 수치 (JSON). 밸런스는 여기만 고치면 돼요.
- `scripts/sim/` 시뮬레이션 (설비마다 파일 하나).
- `scripts/view/` 화면 그리기와 UI (`debug_overlay.gd` 디버그 오버레이).
- `tests/` 시뮬레이션 테스트.
- `scripts/demo.gd` 예시 공장.

## 참고
- Godot 4.3 stable에서 실행·테스트했어요. 오류가 뜨면 **출력(Output) 창의 빨간 줄**을 그대로 보내 주세요.
- 내보내기(Export)할 때는 내보내기 설정의 '리소스 외 파일 포함'에 `*.json`을 넣어야 데이터가 들어가요.
