# DUNI ARENA — 처음 시작하는 플레이어를 위한 게임 설명 기획서

작성일: 2026-10-18  
대상: DUNI ARENA를 처음 접하는 플레이어  
기준: 현재 Godot 구현  
문서 목적: 게임 소개·플레이 가이드·첫 플레이 안내의 기준을 정한다. 새로운 게임 규칙을 추가하는 제안은 포함하지 않는다. 아래의 안내 화면·문구는 제작 제안이며, 이미 게임에 구현된 튜토리얼이라는 의미는 아니다.

## 1. 게임을 한 문장으로 설명하기

> **길드원을 모으고, 전장에 배치하고, 전투의 결정적인 순간에 개입하며 15층 타워를 정복하는 자동전투 전략 게임.**

플레이어는 길드를 이끄는 지휘관이다. 유닛의 이동과 기본공격은 AI가 담당한다. 플레이어는 누구를 출전시킬지, 어디에 배치할지, 누구를 성장시킬지 결정한다. 전투 중에는 터닝포인트와 전략카드, 직접 조준하는 초월, 후퇴 판단으로 전황에 개입한다.

전투의 재미는 싸움이 시작되기 전의 준비와 싸움이 벌어진 뒤의 판단이 이어지는 데 있다. 적을 모두 쓰러뜨리는 것뿐 아니라, 길드의 체력·기력·재화를 관리하며 다음 전투를 준비해야 한다.

### 처음 보여줄 소개 문구

**짧은 소개**

> 당신은 길드의 지휘관입니다. 전열을 세우고 후열을 지키세요. 전투는 유닛들이, 결정적인 선택은 당신이 합니다.

**상세 소개**

> 26종의 캐릭터로 길드를 구성하고 3개 챕터, 15층의 타워를 공략하세요. 전투 전에는 진형과 장비를 준비하고, 전투 중에는 터닝포인트에서 전략을 바꿉니다. 초월이 준비되면 직접 방향을 정해 전황을 흔드세요. 필요하다면 후퇴하고, 손상된 적에게 다시 도전할 수도 있습니다.

## 2. 목표와 승리·종료 조건

### 최종 목표

타워의 다음 층을 차례로 열고, 마지막 15층의 보스를 처치하면서 해당 층의 진행 조건을 충족해 타워를 정복한다. 보스만 처치하면 언제나 다음 챕터로 넘어가는 것은 아니다. 층마다 표시된 방 완료 조건도 확인해야 한다.

타워 정복과 모든 방 완료는 별개다. 타워를 정복한 후에도 남아 있는 방을 탐험할 수 있다.

### 전투 목표

일반적인 전투에서는 아군이 살아 있는 동안 적을 모두 쓰러뜨리면 승리한다. 아군 출전 유닛이 모두 쓰러져도 예비 길드원과 플레이어 HP가 남아 있다면 런을 이어가며 재도전할 수 있다.

### 런 종료

- 플레이어 HP가 0이 된다.
- 정산 후 살아 있는 길드원이 아무도 남지 않는다.
- 플레이어가 타워 포기를 확정한다.

**안내에서 강조할 점:** 길드원 한 명의 사망과 게임오버는 같은 뜻이 아니다. 반대로 전투에서 적을 모두 쓰러뜨려도 플레이어 HP가 0이면 런을 이어갈 수 없다.

## 3. 전체 플레이 흐름

**새 게임 / 이어하기 → 타워 지도 → 방 선택 → 정비·배치 → 자동전투와 전술 개입 → 결과 확인 → 길드 관리·다음 방 → 층 해금 → 보스·다음 챕터**

| 단계 | 플레이어가 하는 일 | 주요 판단 |
| --- | --- | --- |
| 타워 지도 | 해금된 층에서 방을 고른다 | 전투를 이어갈지, 휴식·모집·상점을 이용할지 |
| 정비 | 길드원의 HP·기력·장비·강화를 확인한다 | 누구를 출전시키고 누구를 쉬게 할지 |
| 배치 | 출전할 길드원을 아군 영역에 놓는다 | 전열·후열·지원 유닛의 위치 |
| 전투 | 전황을 관찰하고 개입한다 | 성향·카드·초월·후퇴 시점 |
| 결과 | 손실·보상·생존자 상태를 확인한다 | 재도전 또는 다음 방 |
| 성장 | 영입·강화·장비·승급을 진행한다 | 한 명의 집중 성장 또는 길드 전력 보강 |

타워는 연결된 갈림길을 따라 한 방향으로만 이동하는 맵이 아니다. 해금된 층 안에서는 원하는 방을 선택할 수 있다. 보이지 않는 방은 들어가 보기 전까지 정확한 종류를 알 수 없다.

## 4. 처음 시작할 때 알아야 할 것

### 초기 길드와 재화

현재 새 런은 다음 상태로 시작한다.

| 항목 | 초기 상태 |
| --- | --- |
| 길드 | 전사 2명, 궁수 1명, 힐러 1명 |
| 플레이어 HP | 100 / 100 |
| 골드 | 1,200 G |
| 토큰 | 5개 |
| 전략카드 | 망고주스 1장, 전투회피 1장, 보호막 2장 |
| 길드원 | Lv. 0, 0성, 기력 5 |

### 첫 진형 예시

- **전사 2명:** 적과 먼저 만나는 앞쪽에 나누어 배치한다.
- **궁수:** 전사 뒤에서 공격할 수 있도록 둔다.
- **힐러:** 전열 바로 앞에 노출되지 않는 후방에 둔다.

이것은 초보자를 위한 출발점이다. 적의 구성과 각 캐릭터 능력에 따라 배치는 달라질 수 있으며, 이 배치가 승리를 보장하지는 않는다.

전투가 시작되면 유닛은 처음 배치한 자리에 고정되지 않는다. AI가 적을 찾고 접근·거리 조정·회피·공격을 수행한다.

## 5. 화면에서 읽어야 할 핵심 정보

| 정보 | 의미 | 초보자가 해야 할 판단 |
| --- | --- | --- |
| 플레이어 HP | 런 전체를 유지하는 생명력 | 손실이 누적되면 무리한 전투를 피한다 |
| 유닛 HP | 개별 길드원의 생존 상태 | 치유·교대·후퇴가 필요한지 본다 |
| 기력 | 출전과 휴식으로 변하는 컨디션 | 같은 유닛만 계속 출전시키지 않는다 |
| 골드 | 영입·강화·상점 등에 사용하는 재화 | 당장 필요한 전력을 우선한다 |
| 토큰 | 일부 영입·콘텐츠 등에서 요구하는 재화 | 골드와 별도 비용인지 확인한다 |
| 궁극기 게이지 | 유닛 고유 궁극기의 준비 정도 | 준비가 끝나도 AI가 상황을 보고 사용한다 |
| 초월 게이지 | 플레이어가 직접 개입하는 기술의 준비 정도 | 방향과 적의 위치를 보고 직접 사용한다 |

### 가장 중요한 구분: 두 종류의 HP

**유닛 HP는 길드원 개인의 체력이고, 플레이어 HP는 이번 타워 도전 전체의 생명력이다.**

길드원이 전투에서 사망하면 플레이어 HP도 감소한다. 손실량은 캐릭터마다 다를 수 있다. 전투 패배에는 별도의 플레이어 HP 손실도 발생한다. 유닛을 치유한다고 플레이어 HP가 함께 회복되는 것은 아니다.

사망한 길드원은 목록에 남는다. 부활이나 허용된 성장·회복 경로를 통해 다시 사용할 수 있지만, HP가 0인 상태에서는 배치할 수 없다.

## 6. 전투에서 플레이어가 하는 일

### 자동으로 진행되는 일

유닛의 이동·타겟 탐색·기본공격·패시브·상황에 따른 방어 행동·궁극기 판단은 자동으로 진행된다. 궁극기는 게이지가 가득 찼다는 이유만으로 항상 즉시 사용되지는 않는다.

패링은 공격을 받아쳐 빈틈을 만드는 행동이고, 상쇄는 공격끼리 충돌하는 현상이다. 넉백과 상태이상도 전투 흐름에 영향을 준다. 초보자에게는 정확한 공식을 먼저 설명하기보다 **밝은 패링 파동, 공격 충돌, 기절 표시, 보호막**을 알아보게 한다.

### 터닝포인트: 멈춘 전장에서 전략 바꾸기

전투가 일정 시점에 도달하면 감속 후 정지하며 터닝포인트가 시작된다. 이때 아군을 선택하고 전투 성향을 바꾸거나 전략카드를 사용할 수 있다. 준비가 끝나면 전투를 재개한다. 선택 시간에는 제한이 있다.

첫 터닝포인트는 전투 시뮬레이션 시간 12초에 시작하며, 이후 30초 간격으로 예정된다. 감속은 2초, 정지 선택 시간은 최대 40초다. 안내 본문에서는 숫자를 전부 나열하기보다 남은 시간 표시를 먼저 읽게 한다.

| 전투 성향 | 처음 보여줄 설명 |
| --- | --- |
| 기본 | 기본 전투 판단을 따른다. |
| 신중함 | 위험과 방어 대응을 더 신경 쓴다. |
| 저돌적 | 공격적으로 압박하지만 위험 부담도 커진다. |
| 엄호 | 보호할 아군을 고려해 위치를 잡고 방어한다. |

성향은 유닛을 직접 조종하는 명령이 아니다. AI의 행동 우선순위와 관련 수치에 영향을 준다.

### 전략카드: 필요한 유닛에게 필요한 효과

카드를 선택하고, 대상이 필요한 카드라면 적용할 유닛을 선택해 사용한다. 카드마다 일회성·층별 사용 제한·재사용 조건이 다르므로 사용 가능 표시와 설명을 확인한다.

| 카드 | 초보자용 설명 |
| --- | --- |
| 망고주스 | 유닛을 치유한다. |
| 전투회피 | 선택한 유닛이 위험에서 벗어나도록 한다. |
| 충전 | 궁극기 게이지 충전을 돕는다. |
| 보호막 | 받는 피해를 막을 보호막을 준다. |
| 철벽방어 | 패링을 활용하는 방어 기회를 제공한다. |
| 도발 | 적의 주의를 끌도록 한다. |

상태이상·은신·인식 조건 등에 따라 효과가 제한될 수 있다. 초보자 안내에서는 실패를 숨기지 말고 현재 사용할 수 없는 이유를 짧게 알려준다.

**전투회피 카드는 선택 유닛의 전술 행동이며, 전투를 끝내는 전체 후퇴와 다르다.**

### 초월: 방향을 정하는 직접 개입

초월이 준비된 아군을 길게 눌러 조준하고, 원하는 방향으로 끌어 놓아 발동한다. 짧게 누르는 것과 조준을 완료하는 것은 구분한다. 충분히 방향을 지정하지 않고 놓으면 발동하지 않으며 게이지도 소모하지 않는다.

초월 중에는 전투가 멈추며 강한 방향성 공격이 발생한다. 적이 모인 방향, 위험한 적의 위치, 아군이 살려야 할 교전 상황을 보고 결정한다. 상태에 따라 게이지가 가득 차도 사용할 수 없는 경우가 있다.

### 전체 후퇴: 남은 전력을 지키고 다시 도전하기

전투 시간 20초 이후, 후퇴 조건을 만족하면 전체 후퇴가 가능하다. 버튼의 가능 상태를 확인한다.

후퇴하면 그 방은 미클리어로 남고 지도로 돌아간다. **적의 남은 HP와 사망 상태 등이 유지되므로 다시 준비해 같은 방에 도전할 수 있다.** 아군의 손실도 되돌아가지 않는다. 후퇴에는 패배의 추가 HP 손실이 적용되지 않지만, 이미 발생한 길드원 사망 손실은 남는다.

## 7. 전투를 이어가기 위한 길드 운영

### HP와 기력 관리

유닛 HP는 방을 옮겼다고 자동으로 전부 회복되지 않는다. 미클리어 전투 방을 처음 승리했을 때 실제 출전한 생존 아군은 기본적으로 최대 HP의 30%를 회복한다. 예비 길드원과 사망자는 이 첫 승리 치유 대상이 아니다. 실제 치유량에는 해당 치유 보정이 반영된다.

전투 정산 시 출전자는 기력이 1 감소하고, 예비 길드원은 기력이 1 회복된다. 기력이 낮으면 전투 능력에 불리한 영향이 있으므로 회복과 교대를 고려한다.

### 모집

모집 방에서 후보를 확인하고 비용을 지불해 영입한다. 같은 캐릭터를 다시 영입해도 별개의 길드원이다. HP·장비·성장 상태를 각각 가진다. 후보는 방을 나갔다 돌아와도 유지되며, 리롤을 사용하면 바뀐다. 현재 리롤 비용은 200 G다.

### 장비

아이템 효과와 장착 대상을 확인한 뒤 장착한다. 기본 장비 슬롯은 2칸이며 1성은 3칸, 2성은 4칸이다. 같은 종류의 장비도 개별 아이템으로 존재한다.

장비는 자유롭게 벗겨 다른 유닛에게 옮기는 방식이 아니다. 재각인을 사용하면 대상의 장비를 회수할 수 있다. 초보자에게는 장착을 확정하기 전에 이 제한을 알려준다.

### 강화와 승급

- **강화:** 골드를 사용해 레벨과 전투 스탯을 높인다. 최대 Lv. 10이며 다음 비용은 현재 레벨에 따라 달라진다.
- **승급:** 승급 방에서 같은 종류·같은 성급의 살아 있는 Lv. 10 길드원 3명을 사용한다. 첫 선택 길드원이 남아 성급이 오르고 레벨은 0이 된다. 나머지 2명은 소모되며 그들의 장비는 반환된다.

승급 안내에서는 ‘3명 중 누가 남고 누가 사라지는가’를 숫자보다 먼저 보여준다.

## 8. 타워의 방과 진행

| 방 | 하는 일 | 처음 확인할 것 |
| --- | --- | --- |
| 전투 | 적을 쓰러뜨리고 보상을 얻는다 | 적 구성과 아군 상태 |
| 미니보스 | 더 강한 전투에 도전한다 | 전력·카드·기력 준비 |
| 보스 | 챕터 진행의 핵심 전투를 한다 | 해당 층 완료 조건도 충족했는지 |
| 모집 | 새 길드원을 영입한다 | 후보와 비용 |
| 상점 | 아이템·전략카드 등의 상품을 구매한다 | 효과·가격·구매 여부 |
| 휴식 | 회복·재화·부활 중 필요한 도움을 고른다 | 이번에 가장 부족한 자원 |
| 이벤트 | 온천·보급·승부예측·승급 등의 선택을 한다 | 선택 결과와 소비 조건 |

방을 처음 발견하면 50 G를 얻는다. 같은 방을 다시 방문해 중복으로 받지는 않는다. 발견·방문·완료는 다른 상태이며, 단순히 방을 열어 보았다고 모든 방이 완료되는 것은 아니다.

상점·모집은 재방문 시 남은 상품·후보 상태를 유지한다. 이미 사용한 휴식·이벤트나 클리어한 전투에서 같은 보상을 반복해서 받는 구조는 아니다.

### 다음 층 해금과 층 전체 정복

일반적으로 층의 방 절반을 올림한 수만큼 완료하면 다음 층이 열린다. 챕터 마지막 층은 보스 처치도 필요하다. 화면의 완료 수와 요구 수를 기준으로 판단한다.

한 층의 **모든 방**을 완료하면 층 전체 정복이 된다. 플레이어 HP 회복과 길드 기력 회복, 추가 보상을 얻는다. 이는 유닛 최대 HP를 영구적으로 높이는 보상이 아니다.

## 9. 첫 플레이 안내 구성 제안

긴 설명을 한 번에 띄우지 않는다. 첫 플레이에 필요한 행동부터 설명하고, 나머지는 해당 기능을 처음 만났을 때 안내한다. 이 절은 안내 제작을 위한 제안이며 현재 게임에 새로운 강제 진행을 추가하지 않는다.

### 안내 UI 원칙

1. 한 번에 핵심 개념 하나만 설명한다.
2. 설명은 대상 버튼·게이지 가까이에 짧게 붙인다.
3. 모바일에서 중요한 조작 버튼을 가리지 않는다.
4. 색만으로 상태를 설명하지 않고 텍스트·아이콘을 함께 쓴다.
5. 전체 설명은 도움말에서 다시 읽을 수 있게 구성한다.
6. 조작 안내 때문에 전투나 TP의 기존 시간 규칙을 바꾸지 않는다. 긴 설명은 전투 밖에서 제공한다.
7. 설명에 자원을 지급하거나 보상을 다시 실행하는 기능을 섞지 않는다.

## 10. 초보자 FAQ — 그대로 사용할 수 있는 답변

**Q. 캐릭터를 직접 움직여야 하나요?**  
이동과 기본공격은 자동입니다. 플레이어는 배치·성향·전략카드·초월·후퇴를 결정합니다.

**Q. 궁극기 게이지가 찼는데 왜 바로 쓰지 않나요?**  
궁극기는 AI가 대상과 상황, 행동 가능 상태를 보고 사용합니다. 게이지가 가득 찼다고 항상 즉시 발동하는 것은 아닙니다.

**Q. 궁극기와 초월은 무엇이 다른가요?**  
궁극기는 캐릭터 고유 능력을 AI가 사용하는 것이고, 초월은 별도 게이지가 준비됐을 때 플레이어가 방향을 정해 쓰는 개입입니다.

**Q. 한 전투에서 졌으면 처음부터 다시 해야 하나요?**  
플레이어 HP와 살아 있는 길드원이 남아 있다면 준비를 바꿔 같은 방에 다시 도전할 수 있습니다. 적에게 입힌 피해와 죽은 적의 상태도 유지됩니다.

**Q. 후퇴하면 모든 것이 원래대로 돌아오나요?**  
아닙니다. 이미 발생한 아군 손실과 적의 손상은 남습니다. 후퇴는 남은 전력을 지키고 준비를 다시 하는 선택입니다.

**Q. 같은 전사를 두 명 영입하면 합쳐지나요?**  
자동으로 합쳐지지 않습니다. 각각 별개 길드원이며 HP·성장·장비를 따로 관리합니다.

**Q. 매번 같은 유닛을 출전시켜도 되나요?**  
가능한 상태라면 출전할 수 있지만 HP와 기력이 누적해서 소모됩니다. 예비 길드원을 활용하고 휴식과 치유를 고려하세요.

**Q. 죽은 길드원은 사라지나요?**  
길드 목록에 남습니다. HP 0일 때는 배치할 수 없고, 허용된 부활 경로로 다시 살릴 수 있습니다. 모든 치유가 사망자를 부활시키는 것은 아닙니다.

**Q. 저장은 언제 되나요?**  
지도와 정비, 구매·성장·방 완료 등 안정된 진행 지점에서 자동저장합니다. 전투 도중 앱을 종료했다면 마지막 전투 시작 전 체크포인트로 복구하며, 중간 전투 프레임을 그대로 이어서 재생하지 않습니다.

## 11. 설명의 공개 순서와 완성 기준

### 첫 소개에서 반드시 전달

- 자동전투지만 플레이어의 준비와 개입이 중요하다.
- 길드를 운영하며 타워를 오른다.
- 유닛 HP와 플레이어 HP가 다르다.
- 터닝포인트·카드·초월로 전투에 개입한다.

### 실제 상황에서 추가 설명

기력 관리, 후퇴·재도전, 장비 회수 제한, 카드별 사용 제한, 승급 소모 규칙, 저장 복구 방식.

### 첫 설명에서 생략

26종 전원의 상세 스킬 수치, AI 내부 판단, 공격 충돌 공식, 성장 계산식, 저장 구조, 개발 단계명. 캐릭터별 상세 정보는 해당 캐릭터 설명으로 분리한다.

### 초보자 이해도 확인 기준

첫 전투를 마친 플레이어가 다음 질문에 답할 수 있으면 핵심 설명이 전달된 것으로 본다.

1. 전투에서 자동으로 진행되는 것과 내가 결정하는 것은 무엇인가?
2. 유닛 HP와 플레이어 HP는 어떻게 다른가?
3. 전사와 궁수·힐러를 어디에 두면 좋을까?
4. 터닝포인트에서 무엇을 바꿀 수 있는가?
5. 궁극기와 초월은 누가 사용하는가?
6. 후퇴한 방에 다시 들어가면 적은 어떤 상태인가?
7. 다음 전투 전에 HP와 기력을 왜 확인해야 하는가?
