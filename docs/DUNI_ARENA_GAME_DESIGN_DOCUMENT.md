## 1. 게임 한눈에 보기

### 한 문장 소개

> **길드원을 모으고 전장에 배치한 뒤, 자동으로 벌어지는 전투의 결정적인 순간에 개입하며 15층 타워를 정복하는 자동전투 전략 로그라이트.**

### 기본 정보

| 항목 | 내용 |
| --- | --- |
| 장르 | 자동전투(오토배틀) + 로그라이트 + 길드 운영 |
| 플랫폼 | Android(세로 화면 우선), 웹 브라우저 미리보기 |
| 엔진 | Godot 4.6 (원작은 HTML/JS 웹 게임 — 이를 이식·확장) |
| 플레이 시점 | 위에서 내려다보는 2D 아레나(800×800 논리 좌표) |
| 플레이어 역할 | 길드 **지휘관** — 유닛을 직접 조종하지 않고 준비·배치·개입을 결정 |
| 세계관 한 줄 | “두니 아레나의 승자가 망고를 얻을 것이다” — 망고를 향해 타워를 오르는 길드 이야기 |

### 핵심 재미 세 가지

1. **준비의 재미** — 어떤 길드원을 영입하고, 누구를 키우고, 어떤 장비를 주고, 어디에 세울지 고민한다.
2. **관전과 개입의 재미** — 32종 캐릭터가 각자 개성대로 싸우는 것을 보다가, 터닝포인트·전략카드·초월·후퇴로 판을 뒤집는다.
3. **운영의 재미** — 유닛 HP·플레이어 HP·골드·토큰을 관리하며 15층까지 버틴다. 한 번의 패배가 끝이 아니라 *손실을 안고 다시 도전*하는 구조다.

## 2. 핵심 게임 루프

### 큰 루프 (한 판 = 한 “런”)

```
새 게임 / 이어하기
   └─▶ 타워 지도 (현재 층의 방 선택)
          ├─▶ 전투 방 ─▶ 배치 ─▶ 자동전투 + 개입 ─▶ 결과·정산
          ├─▶ 모집 / 상점 / 휴식 / 이벤트 방
          └─▶ 길드 관리 (강화·장비·인벤토리)
   └─▶ 계단으로 다음 층 ─▶ 챕터 보스 ─▶ 다음 챕터 … ─▶ 15층 보스 처치 = 타워 정복
```

- 런이 끝나는 조건: **플레이어 HP 0**, **살아 있는 길드원 0명**, 또는 **탐험 포기**. 이 셋은 모두 **타워 정복 실패**다(0.49.0).
  - 전투 중 실패가 정해지면(예: 길드원 사망 손실로 플레이어 HP 0) 전투 패배 연출·결과 없이 곧바로 타워 정복 실패 화면으로 넘어간다. 전투가 끝난 정산에서 실패가 정해져도 같다.
  - 탐험 포기는 경고창(“탐험을 포기하면 바로 타워 정복 실패로 처리되고, 지금까지의 진행은 이어할 수 없습니다”)에서 “포기하기”를 누르면 바로 실패 처리된다.
  - 타워 정복 실패 화면: 화면이 회색으로 가라앉고 기울어진 패널 위에 “타워 정복 실패”가 위에서 한 글자씩 무겁게 내려앉으며, 뒤에 대형 “FAILED”, 실패 사유 한 줄, 회색 재가 떨어진다(패배 곡). 2.2초 뒤 또는 화면을 누르면 **결과 확인 / 메인화면 / 다시하기** 버튼이 나온다.
    - 결과 확인: 실패 사유, 도달 챕터·층, 정복한 방 수, 남은 골드·토큰, 길드원(생존) 수, 플레이어 HP.
    - 메인화면: 저장을 지우고 메인 화면으로. **이어하기는 없다**(메인 화면은 실패한 런의 저장이 남아 있어도 지우고 없는 것으로 본다).
    - 다시하기: 그 자리에서 새 런을 시작한다(저장도 새 런으로 덮어쓴다).
- 길드원 한 명이 죽어도 런은 계속된다. 예비 길드원이 있고 플레이어 HP가 남아 있으면 재도전할 수 있다.

### 작은 루프 (전투 한 번)

```
배치(전투 준비) ─▶ 전투 시작 ─▶ 12초: 첫 터닝포인트 (전략 변경) ─▶ 이후 30초마다 터닝포인트
                       │                         │
                       ├─ 초월 게이지가 차면 플레이어가 직접 조준해 발동
                       └─ 20초 이후 조건을 만족하면 전체 후퇴 가능
─▶ 승리 / 패배 / 후퇴 ─▶ 결과 화면(손실·보상) ─▶ 지도로
```

## 3. 게임 모드

| 모드 | 설명 | 상태 |
| --- | --- | --- |
| **두니 타워 오르기** | 본편. 3챕터 15층 로그라이트 런. 자동저장·이어하기 지원 | 구현 |
| **커스텀 전투** | 원하는 캐릭터를 자유롭게 배치해 최대 4팀 + 개인전으로 싸움을 시험하는 샌드박스 | 구현 (원작 웹의 커스텀 전투를 이식·확장) |
| 설정 | 진동 / UI 애니메이션 / 화면 흔들림 켜고 끄기, 버전 표시 | 구현 |

메인 화면 구성 (0.44.0):

- **배경**: 컷신풍 자연 풍경. 맑은 하늘과 흘러가는 뭉게구름, 눈 덮인 먼 산맥, 먼 능선 위의 두니 타워(빛나는 꼭대기 수정), 초록 계곡과 작은 마을, 탑으로 굽이쳐 올라가는 흙길, 왼쪽 숲 비탈, 앞쪽의 짙은 수풀. 깊이가 다른 9개 레이어(하늘·구름·새·먼 산·탑 능선·계곡·중간 언덕·숲 비탈·가까운 언덕·전경)로 그려, 화면 크기에 맞춰 탑을 중심으로 꽉 채운다(가로 화면은 덜 확대해 탑 전체가 보이고 메뉴는 왼쪽에 둔다).
- **로고**: "DUNI ARENA" 글자만 쓴다(ARENA는 강조색).
- **버튼**: 가로 직사각형 버튼 3개를 세로로 정렬 — **타워 입장**(강조) / **커스텀 전투** / **설정**.
- **타워 입장**: 진행 중인 저장이 없으면 바로 새 게임을 시작한다. 있으면 "두니 타워" 창이 열려 저장 요약(챕터·층·HP·골드·길드원 수·마지막 저장 시각)과 **이어하기** / **새로하기**를 고른다(새로하기는 교체 확인을 한 번 더 묻는다).
- **연출**: 메인 화면에 들어올 때 레이어가 먼 것부터 차례로 떠오르며 카메라가 살짝 물러나고(2.4초), 메뉴는 그 뒤에 서서히 나타난다. 타워에 들어갈 때는 카메라가 탑으로 빨려 들어가며(1.5초) 가까운 레이어부터 빠르게 화면 밖으로 지나가고, 하얗게 밝아지며 탐험 화면으로 넘어간다. UI 애니메이션을 끄면 연출 없이 바로 넘어간다.

## 4. 두니 타워 구조

### 층과 챕터

| 항목 | 값 |
| --- | --- |
| 전체 | **3챕터 × 5층 = 15층** |
| 챕터 이름(임시) | 1챕터 “무너진 회랑” · 2챕터 “붉은 첨탑” · 3챕터 “망고의 정상” |
| 층당 방 수 | `6 + ⌊층 번호(0부터) / 3⌋` → 1~3층은 6개, 4~6층은 7개 … 13~15층은 10개 |
| 층 이동 | 그 층 방의 절반(올림)을 완료하면 지도 무작위 위치에 **다음 층 계단**이 나타난다(챕터 마지막 층은 보스 처치도 필요). 계단으로 올라가면 **지나온 층의 방은 다시 들어갈 수 없다** |
| 층 정복 | 그 층의 **모든 방**을 완료하면 층 정복 보상(플레이어 HP 회복, 추가 보상 — 길드 HP +20% / 토큰 +2 / 아이템 중 하나) |
| 챕터 정복 | 챕터 보스를 처치하면 계단이 열리고, 계단으로 다음 챕터에 오를 때 **챕터 클리어 컷신**(층들이 빛나며 폭발해 가루가 되고, 위층이 내려앉은 뒤 다음 챕터 입장)이 나온다 |
| 방 발견 보상 | 처음 들어간 방마다 +50 G (한 번만) |

### 층별 방 구성 규칙

- **1층(고정)** — 모집, 상점, 휴식, 전투, 이벤트, 전투 (튜토리얼 성격)
- **각 챕터 3번째 층** — 방 목록 가운데에 **미니보스** 방이 들어간다.
- **각 챕터 5번째 층** — **보스** 방과 휴식·이벤트 방으로만 구성된다.
- **그 밖의 층** — 대략 전투 40%, 휴식 15%, 서비스(모집·상점) 25%(1~4개), 나머지는 이벤트.
- 방은 현재 층 안에서 **원하는 순서로** 고를 수 있다(길은 장식). 처음 보는 방은 종류가 “?”로 가려져 있다.
- **지도**: 현재 층의 방만 보여 주는 어두운 던전 지도. 크고 작은 돌방(벽돌 벽·타일 바닥, 미탐험 방은 안개)이 흩어져 있고, 다른 방을 피해 꺾이는 돌 통로와 문으로 이어진다. 계단 방은 빛나는 아치 계단. 지도 화면에 들어올 때 좌우로 펼쳐진다.
- **컷신**: 새 게임 시작 시 하늘로 끝없이 뻗은 탑 전경(탑은 화면 가운데, 배경 레이어만 옆으로 흐름, 하늘·설산·숲·초원이 거리별 레이어로 움직임, 챕터마다 회랑·장미창·흉벽이 있는 탑 단) → 빠른 확대 → 1챕터 층들과 챕터 제목. 이어하기 시에는 챕터 제목 장면만. 컷신 중에는 UI가 자연스럽게 사라지고, 화면을 누르면 건너뛴다.

### 적 구성 규칙 (전투 방)

| 항목 | 규칙 |
| --- | --- |
| 일반 전투 적 수 | `3 + ⌊층×0.7⌋ (+0~1)`, 최대 12 |
| 미니보스 방 | 엘리트 1 + 일반, 총 `2 + ⌊층/6⌋ (+0~1)`, 최대 6 |
| 보스 방 | 보스 1 + 엘리트 1 + 일반, 총 `4 + ⌊층/5⌋ (+0~1)`, 최대 7 |
| 적 평균 레벨 | `⌊층×1.6 + 0.5⌋` (층이 오를수록 강해짐, 개체마다 ±1 분배) |
| 엘리트 배율 | 크기 1.5배 · HP ×2.5 · 공격력 ×1.65 · 방어 ×1.5 · 속도 ×1.08 |
| 보스 배율 | 크기 1.85배 · HP ×3.6 · 공격력 ×2.15 · 방어 ×2 · 속도 ×1.12 |
| 보스 후보 | 전사, 마법사, 수호자, 샷건, UFC 선수, 두비두밤, 챌런, 포식자, 폭탄 |
| 적 진형 | 전열 / 분산 / 쌍익 / 포위 / 밀집 — 5종 중 무작위 |
| 적 역할 배분 | 전열(근접)·원거리·지원 풀에서 고르게 뽑아 한 방에 같은 캐릭터가 겹치지 않게 구성(같은 종류 최대 2) |
| 초반 가중치 | 1~3층은 싼 캐릭터가 더 자주 나온다 |

## 5. 방(Room) 종류

| 방 | 하는 일 | 핵심 규칙 |
| --- | --- | --- |
| **전투** | 적을 모두 쓰러뜨린다 | 보상 골드 `350 + 50×층` (승리해도 유닛 HP는 회복되지 않는다) |
| **미니보스** | 강한 엘리트가 낀 전투 | 보상 700 G |
| **보스** | 챕터 보스 전투 | 보상 1,000 G, 챕터 진행의 열쇠 |
| **길드원 모집** | 후보 3명 중 영입 | 비용은 **토큰**(캐릭터별 2~5개). 리롤 200 G. 후보는 재방문해도 유지 |
| **상점** | 장비 / 전략카드 구매, 인벤토리 확인 | 탭 3개(장비 구매 · 전략카드 · 인벤토리). 산 상품은 “구매 완료” |
| **길드 휴식소** | 4개 중 1개 선택 | 플레이어 HP +15 / 골드 +350·토큰 +1 / 생존 유닛 HP +35% / 사망 유닛 최대 3명 부활(HP 20%, 0.50.0에서 2명 → 3명) |
| **이벤트 · 온천** | 2개 중 선택 | 온천욕: 생존 유닛 HP +10% / 복권(200 G): 아이템·골드·토큰·전략카드·유닛 중 무작위 |

## 6. 전투 시스템

### 6-1. 기본

- **800×800 아레나**에서 아군(왼쪽 배치 구역)과 적(오른쪽)이 자동으로 싸운다.
- 아레나 바닥은 깔끔한 벡터 일러스트풍 풀밭이다(경기장은 탑 내부). 차분한 2~3톤 초록 풀에 넓고 구불구불한 흙길(좌우 갈래), 길 위에만 놓인 몇 개의 디딤돌, 물웅덩이, 작은 꽃과 풀포기가 있다. 가장자리 곳곳에 짙은 그늘이 바람에 흔들리듯 천천히 움직이고, 룬 석주의 그림자도 진다. 경기장은 덤불 울타리로 둘러져 있고, 그 너머(경기장 크기만큼 넓게)에는 이끼 낀 바위 무더기, 서 있는·부러진 돌기둥, 석상을 얹은 기둥, 쓰러진 기둥 조각, 몇 그루의 나무가 그림자와 함께 무리 지어 있고, 멀수록 구조물이 커지다가 가장자리는 큰 바위 더미로 완전히 덮인다. 배치·전투 화면에서는 이 풍경이 정사각형 경기장 밖 화면 전체에도 카메라와 맞춰 비치고, 화면 위아래 끝으로 갈수록(필드는 가리지 않는 선까지) 어두워진다. 세로가 긴 화면에서는 남는 높이 일부를 필드 영역에 줘 하단 조작 UI가 조금 아래에 놓인다(셰이더로 한 번 그려 둔 바닥 텍스처 + 그림자 텍스처 두 장).
- 유닛의 **이동·타겟 선택·기본공격·방어 반응·궁극기 사용**은 모두 AI가 한다.
- 플레이어는 **배치 → 성향·전략카드(터닝포인트) → 초월 → 후퇴**로 개입한다.
- 한 전투에 **출정**할 수 있는 유닛 수는 기본 **3명**이다(길드 관리 "강화" 탭의 출정 수 업그레이드로 최대 8명). 배치 화면 도구줄에 "출정 현재/최대"가 표시되고, 최대에 도달하면 더 배치할 수 없다(배치된 유닛 옮기기는 가능).
- 배속: 1× / 2× / 4× (시각 효과도 같은 배속으로 재생). 일시정지 가능.

**피해 인스턴스와 태그**: 모든 피해 인스턴스는 **물리 또는 마법 중 정확히 하나**의 유형과, 위 목록의 태그(속성 7종 + 폭발·범위·투사체·지속)를 0개 이상 가진다. 한 유닛이 유형을 섞어 쓸 수 있다(예: 탱크 포탄은 물리, 화염 지대는 마법). 정의는 데이터(`UnitStatTable.DAMAGE`)에 있고, 계산 코드는 태그를 읽기만 한다.

```
원피해  = 기본값 + (물리 피해 또는 마법 피해) × 계수
피해    = 원피해 × 공격력%
          × (1 + 맞는 속성·태그 보너스의 합)
          × 속성 피해%        (속성 태그가 있을 때만)
          × 치명타 피해량%    (치명타일 때만)
          × 궁극기 피해량%    (궁극기 피해일 때만)
방어    = 방어력 + (물리 방어력 또는 마법 방어력)
최종    = 피해 × 100 / (100 + 방어)          방어 ≥ 0
최종    = 피해 × (2 − 100 / (100 − 방어))    방어 < 0
```

- 100은 따로 조정할 수 있는 상수(`UnitStatTable.MITIGATION`)다. 방어 100이면 피해 절반, 방어 −100이면 1.5배.
- 그 뒤에 기존 규칙(저돌적 ×1.2·신중함 ×0.85·저주의 받는 피해 변화, 수호자 0.8배, 60초 이후 피해 가속, 고유 방어·패링 절반 등)이 그대로 이어진다.
- **반사·공유·분배 피해**(금간 거울 반사·파편, 자석 공유, 인형술사 분담)는 원래 피해의 유형·태그를 유지하되 **받는 쪽의 방어만** 적용된다(공격력·보너스·치명타는 다시 곱하지 않는다).
- 처형·기절 등 피해가 아닌 효과는 예전 그대로다. 가위바위보 승부 결과는 이제 최대 HP 비율이 아니라 위 공식의 피해 인스턴스다.
- 레벨 성장: 최대 HP +12%, 물리·마법 피해 +8%, 방어력 +8%, 이동속도 +2% (물리·마법 방어력은 고정). 적은 기본값 ×0.8에 같은 레벨 성장을 받고, 엘리트·보스의 피해 배율은 **공격력%**, 방어 배율은 방어력·물리 방어·마법 방어 모두에 곱해진다.
- 패링 성공률은 방어력 ÷ 상대 공격 세기(주 피해 스탯 × 공격력%)로 계산한다.

### 6-3b. 처치 기록과 연속 킬

- **킬 로그**: 필드 위 상태줄의 "전투 중"과 전투 시간 사이에 "처치한 유닛 / 쓰러진 유닛" 캡슐 하나가 3초간 표시된다. 크기는 항상 같고, 양끝이 각 팀 색으로 물들며, 새 처치가 나오면 위에서 미끄러져 들어와 이전 줄을 밀어낸다.
- **연속 킬** (원작 연출): 한 유닛이 6초 안에 연달아 처치하면 필드 위쪽에 **더블 킬 → 트리플 킬 → 쿼드라 킬 → 펜타 킬 → 헥사 킬** 리본 배너가 2.6초간 뜬다. 리본이 좌우로 펼쳐진 뒤 빛이 한 번 훑고 지나가며, 처치 유닛 초상·이름과 처치 수만큼의 마름모 눈금이 함께 표시된다. 다른 유닛의 연속 킬은 차례를 기다리고, 마지막 처치로 전투가 끝나도 승리 연출 위에 그대로 나온다(타워 전투 포함).
- 필드 유닛의 HP바(팀 색)와 궁극기 바는 화면이 작아져도 일정 크기 이상으로 보이도록 그려진다.
- 필드의 유닛 테두리는 캐릭터 고유 색이 아니라 **팀 색**(아군 파랑 / 적 빨강, 커스텀은 팀별 색)으로 그려진다.

### 6-4. 터닝포인트 (TP)

- **12초에 첫 TP**, 이후 **30초 간격**(42초, 72초…).
- 2초간 감속 → 정지. 정지 상태에서 **최대 40초** 동안 전략을 고른다.
- 할 수 있는 것: 아군을 골라 **전투 성향** 변경, **전략카드** 사용, 전투 재개, 후퇴.
- TP의 카드 줄에는 **지금 쓸 수 있는 카드만** 나온다(0.50.0). 써 버린 일회성 카드는 TP와 인벤토리에서 사라지고, 쿨타임 중이거나 이번 층에 이미 쓴 카드는 TP에 보이지 않는다(인벤토리에는 “대기” 칸으로 남는다).
- 필드 조작: 두 손가락으로 확대·축소, 확대한 상태에서 한 손가락 드래그로 시점 이동, 필드의 아군을 누르면 하단 유닛도 함께 선택된다. 유닛은 어두워지지 않고 바닥만 살짝 어두워진다.

| 성향 | 효과 |
| --- | --- |
| 기본 | 캐릭터 고유의 판단을 따른다. 상황 판단에 따라 두 성향의 움직임이 섞여 보인다 |
| 신중함 | 측면으로 돌아 들어가 치고 빠진다. 받는 피해 ×0.85, 막아 낸 뒤 반격 강화 |
| 저돌적 | 가장 가까운 적에게 곧장 붙어 쉬지 않고 친다. 주는 피해 ×1.1, 받는 피해 ×1.2 |
| 엄호 | 보호할 아군 곁을 지키며 날아오는 공격을 몸으로 막는다 (0.42.0에서 변경 없음) |

#### 플레이어 성향 상세 (0.42.0)

각 성향은 항상 작동하는 이득과 손해를 하나씩 갖고, 나머지 차이는 **움직임**(기존 이동 모드의 가중치, 타깃 판단, 위치 판단)으로 만든다. 새 동작이나 애니메이션은 없다. 모든 수치는 `scripts/stance_rules.gd`(`StanceRules`) 한 곳에 있다. 아래 효과는 **플레이어가 고른 성향에서만** 켜지고, 상황 판단(기분 점수)으로는 절대 켜지지 않는다. 커스텀 전투와 두니 타워에 적용되며, Phase 1~7 골든 하네스는 예전 웹 수치를 유지한다.

| 항상 작동하는 손해 | 받는 피해 ×1.2 | 공격 가동률이 낮다 (선공 대기, 공격 지연 ×1.15, 다음 공격 대기 ×1.25) |

**반격 강화 (신중함 전용)**: 회피 또는 패링(자체 회피, 캐릭터 회피 포함)에 성공하면 3초 안의 다음 공격 피해가 **+50%**, 막아 낸 공격이 저돌적 성향 유닛의 것이면 **+100%**. 중첩되지 않고 다시 성공하면 지속 시간만 갱신된다. 준비된 동안 유닛의 HP바 오른쪽에 작은 금색 마름모가 깜빡인다.

**표시**: 필드 유닛의 HP바 왼쪽에 플레이어 성향 아이콘이 작게 고정 표시된다(저돌적 주황 꺾쇠, 신중함 청록 방패, 엄호 파란 고리, 기본은 없음). 상황 판단이 "돌격"(+0.45 초과) 또는 "신중"(−0.3 미만)으로 **바뀌는 순간에만** 머리 위에 "돌격!"/"신중" 글자가 0.9초 떠올랐다 사라진다. 아이콘은 화면 기준 약 9px로, 유닛이 많아도 HP바 옆 자리만 쓴다.

**측정 (시드 고정 3대3, 역할·성향별 40판, 조정 전 → 조정 후)**: 아군 3명은 한 역할(근접형 전사·UFC·검객 / 대치형 히어로·금간 거울·기관총 / 후열 궁수·마법사·폭탄)로 같은 성향을, 적은 기본 성향의 혼합 편성(전사·히어로·궁수)을 쓴다. 아군 배치와 시드는 성향만 바꿔 동일하다. 공격 가동률은 살아 있는 시간 중 공격·궁극기 동작 비율, 공격 직후 후퇴는 공격이 끝난 뒤 0.6초의 1/3 이상을 스스로 타깃 반대로 움직인 비율(넉백·겹침 밀림 제외), 추격 거리는 한 번 붙은 타깃이 사거리 +40 밖에 있을 때 타깃 쪽으로 다가간 거리다.

#### 적의 특수전략 (0.39.0)

- 적은 TP마다 상황에 따라 **확률적으로** 특수전략을 준비한다. 모든 적이 쓰는 것은 아니다.
- **TP마다 적의 수 · 챕터(탑 진행도) · 방 종류(일반 전투 / 미니보스 / 챕터 보스)로 정해진다** (0.53.0). `EnemyStrategyPlanner`
  - **위험도** = 진행도(1층 0 → 15층 1) + 방 가중치(미니보스 +0.15, 챕터 보스 +0.3).
  - 적 한 명이 행동할 확률 = (0.12 + 0.55 × 위험도) × 적 수 보정(√(3 / 적 수), 0.55~1.5) + 등급 보정(엘리트 +0.1, 보스 +0.25), 최대 90%. 초반에는 거의 쓰지 않고, 적이 적을수록 한 명 한 명이 자주 쓴다.
  - 특수행동은 **일반 / 위험 / 고위험** 등급이 있다. 먼저 등급을 고르고(가중치 일반 1, 위험 0.2 + 0.8 × 위험도, 고위험 (위험도 − 0.3) × 1.5), 그 등급 안에서 상황에 맞는 행동을 고른다. 고위험은 위험도 0.3 이상에서만 나오고, TP 하나에 최대 (위험도 0.3 이상 1 + 0.9 이상 1 + 챕터 보스 방 1)개까지.
  - 배지에 등급이 표시된다: 위험은 주황 테두리와 “!”, 고위험은 붉게 맥박치는 테두리와 “!!”. 상세 카드에 “○○ · 고위험 특수행동”처럼 등급이 나온다.
- TP 동안 준비 중인 전략이 적의 머리 위 배지로 보인다. 배지나 적을 누르면 상세 카드가 열리고, 한 번 더 누르면 유닛 설명창이 열린다. 공격·이동 전략은 범위나 경로가 바닥에 표시된다.
- TP가 끝나면 남아 있는 적의 특수전략이 바로 사용된다. 강타와 가르기는 **0.6초 예고** 뒤에 발동하고, 그 사이 기절하면 취소된다. 도발 카드에 걸린 적은 이동·강타·가르기가 끊긴다. 특수전략을 막는 능력(초월, 전략카드 등)은 추후 추가 예정이다.

## 7. 길드원 성장과 관리

### 길드원은 “개인”이다

같은 캐릭터를 두 번 영입해도 합쳐지지 않는다. 각 길드원은 자기만의 **HP, 레벨, 성급, 장비**를 가진다. 길드원은 `#1, #2 …` 번호로 구분한다.

### 초기 길드 (새 런)

전사 2명, 궁수 1명, 힐러 1명 · 골드 1,200 · 토큰 5 · 플레이어 HP 100 · 전략카드 망고주스 1, 전투회피 1, 보호막 2.

### 경험치와 레벨 (0.40.0)

레벨은 골드로 **경험치(EXP)를 사서** 올린다. 길드 관리 "강화" 탭에서 경험치는 **100 EXP 묶음**으로 산다(상수 `GrowthRules.EXP_PACK`).

- **EXP +100** 버튼: 100 EXP(100 G)를 한 번 산다.
- **즉시 레벨업** 버튼: 다음 레벨까지 필요한 만큼 100 EXP 묶음을 자동으로 n개 산다(`n = ⌈남은 EXP / 100⌉`, 비용 n × 100 G). 넘치는 경험치는 다음 레벨 진행도로 남는다.

| 항목 | 값 |
| --- | --- |
| 환율 | **1 G = 1 EXP** (상수 `GrowthRules.EXP_PER_GOLD`) |
| 레벨 L → L+1 필요 EXP | `80 + 20 × L` (Lv.0→1: 80 … Lv.9→10: 260 … 상한 없음) |
| 누적 EXP | 각 유닛은 Lv.0부터 얻은 **누적 경험치**를 저장하고, 레벨과 레벨 사이 진행도는 여기서 계산한다. 남는 경험치는 사라지지 않는다 |
| Lv.L까지 누적 EXP | `80L + 10L(L−1)` (Lv.10 = 1,700) |
| 레벨 상한 | 없음 |
| 레벨당 성장 | 최대 HP +12%, 물리·마법 피해 +8%, 방어력 +8%, 이동속도 +2% (기본값 대비, 누적. 레벨 상한 없이 계속 적용) |

### 출정 수 업그레이드

| 단계 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 출정 최대 | 3명 | 4명 | 5명 | 6명 | 7명 | 8명 |
| 다음 단계 비용 | 500 G | 800 G | 1,200 G | 1,700 G | 2,300 G | — |

- 비용 증가폭은 `300 + 100n` (상수 `GrowthRules.SORTIE_COSTS`). 업그레이드 단계는 런 저장 데이터에 들어간다.
- 길드 관리 "강화" 탭 하단의 원형 **출정 수 업그레이드** 버튼으로 산다(버튼 아래에 "출정 3→4명 · 500G"처럼 표시).

### 성급(★) 승급

- 길드 관리 "강화" 탭 하단의 원형 **승급** 버튼으로 승급 창을 연다(승급 이벤트 방은 없어졌다).
- 조건: **생존한 같은 캐릭터·같은 성급 유닛 3명**. 레벨 조건 없음. 성급은 ★2까지.
- 승급 창에서 **주 유닛 1명과 재료 유닛 2명**을 고른다. 주 유닛이 남아 ★ +1, 재료 2명은 소모된다. 결과 레벨 같은 정확한 수치는 승급 전에 보여 주지 않고, 승급 연출에서 공개한다.
- **경험치**: 결과 누적 EXP = 세 유닛 누적 EXP 합 + **승급 보너스 EXP**(`GrowthRules.PROMOTION_BONUS_EXP`, 임시 300). 이 값으로 레벨과 진행도를 다시 계산한다.
- **스탯**: ★ 자체의 스탯 보너스는 없다(예전 "★1 = 레벨 40개분" 보너스는 승급 보너스 EXP로 대체). 장비 칸은 기존대로 기본 2 → ★1 3칸 → ★2 4칸.
- **HP**: 세 유닛 현재 HP의 평균. 새 최대 HP(옮겨 온 장비 포함)를 넘으면 최대 HP로 맞춘다.
- **장비**: 주 유닛의 장비는 그대로 둔다. 재료 2명의 장비를 모아 주 유닛의 빈 칸에 무작위로 장착하되 **고대 > 희귀(조합) > 일반·구형** 순으로 먼저 넣는다. 장착 중 일반 아이템끼리 만나면 평소처럼 자동 조합된다. 칸이 모자라 남은 장비는 인벤토리로 돌아간다.

### 장비

- 장비는 칸 수만큼 장착한다. **자유롭게 해제할 수 없고**, 회수하려면 소모품 “재각인”이 필요하다.
- 일반 아이템 2개가 같은 유닛에 모이면 희귀 아이템 1개로 자동 조합된다(10장 참고).

### 기력 (삭제됨)

- 예전의 기력(0~5칸) 시스템은 삭제되었다. 대신 전투에서 이겨도 유닛 HP가 회복되지 않으므로, HP 관리(휴식·온천·보물상자·층 정복 보상·전략카드)가 운영의 중심이다.

### HP와 사망

- 유닛 HP는 방을 옮겨도 이어진다. 휴식·온천·망고주스·힐러 등으로 회복한다.
- 죽은 길드원은 목록에 남는다(HP 0, 배치 불가). 휴식소 “사망 유닛 부활”로 되살린다.

### 10-1c. 대장장이 (0.51.0)

- **배치**: 대장장이는 이벤트 방이지만 모집·상점과 같은 **서비스 방 칸**에서 나온다. 1층(고정 배치)과 보스 층에는 나오지 않는다. 각 층의 두 번째 서비스 칸이 50% 확률로 상점 대신 대장장이가 되고, 세 번째 이후 칸은 모집·상점·대장장이 중 하나다(`TowerMapGenerator.BLACKSMITH_CHANCE`). 발견 시 무작위 이벤트로 바뀌지 않는다.
- **강화**: 희귀 아이템만, 골드로 최대 +5. 성공률 100%, 실패·하락 없음. 장착 중인 아이템도 강화할 수 있고(장착 고정 규칙), 승급으로 장비가 옮겨져도 단계는 유지된다. 일반·고대 아이템은 강화할 수 없다.

| 단계 | 비용 | 누적 | 스탯 증가 |
| --- | --- | --- | --- |
| +1 | 200 G | 200 G | +10% |
| +2 | 330 G | 530 G | +20% |
| +3 | 530 G | 1,060 G | +30% |
| +4 | 800 G | 1,860 G | +40% |
| +5 | 1,200 G | 3,060 G | +60%, 이름 금빛 |

  - 증가율은 그 아이템이 올려 주는 **스탯 수치**에 곱해진다(예: 물리 피해 +15% → +5에서 +24%, 최대 HP +30% → +48%). 송곳·토템 같은 **특수 능력과 승리 골드는 그대로**다.
  - 이름 뒤에 단계를 붙인다(예: 굵은 송곳 +3). 화면에는 "+2 → +3 · 스탯 +20% → +30%"와 지금/강화 후 수치를 함께 보여 준다.
- **교환**: 장착하지 않은 일반 아이템 2개를 넣으면 희귀 아이템 3개가 제시된다. 첫째는 두 재료의 정상 조합 결과, 나머지 둘은 무작위 희귀. 1개를 고르면 재료 2개가 소모된다. **방 1회 방문당 2번**. 같은 재료 쌍에는 같은 3개가 제시된다(재료를 바꿔 넣었다 빼는 것으로 다시 뽑을 수 없다).
- **판매**: 장착하지 않은 일반 아이템만, 구매가의 50%. 희귀·고대·장착 중인 아이템은 팔 수 없다. 판 골드는 지갑으로 날아가는 기존 연출로 들어온다.
- 경제: 희귀 1개 = 일반 2개 = 240~320 G. 강화 +1(200 G)은 일반 약 1.5개 값이라 "새 희귀를 만들까, 있는 희귀를 강화할까"를 고르게 되고, +5 누적 3,060 G는 후반 전투 보상 약 3판 분량의 장기 목표다. 판매가를 구매가의 절반으로 둬 사고팔기 반복으로는 이득이 없다.

## 11. 유닛 AI

자동전투 게임에서 AI는 곧 “캐릭터의 연기”다. 현재 AI는 원작 웹 버전의 판단 구조를 그대로 옮긴 뒤 다듬은 것이다.

### 판단 구조

| 단계 | 내용 |
| --- | --- |
| **성격 값** | 유닛마다 대담함·신중함·반응속도·인내심·선호 거리·좌우 성향 등을 무작위로 갖는다 → 같은 캐릭터라도 조금씩 다르게 움직인다 |
| **타겟 선택** | 캐릭터별 우선순위(예: 암살자 = 체력 낮은 후열, 히어로 = 적이 몰린 곳, 개구리 = HP 높은 적) + 거리. 도발·집중 명령·반격·엄호가 있으면 그것을 우선한다 |
| **타겟 유지** *(신규)* | 한 번 고른 타겟은 1.6초 이상 유지한다. 타겟이 사라지거나, 다른 적이 이미 사거리 안에 들어왔거나, 훨씬 가까울 때만 바로 바꾼다 |
| **이동 모드** | 관찰 · 접근 · 선회 · 측면 · 견제 · 후퇴 중 상황(거리, 쿨타임, 주변 적 수, 상대 빈틈)에 따라 가중 확률로 고른다 |
| **위치 잡기** | 후열은 적과 일정 거리를 둔 안전한 “스테이션”을 찾고, 호위형은 지킬 아군 곁에, 의존형은 기준 아군 근처에 선다 |
| **위험 회피** | 폭발·장판·궁극기 예고 범위를 평가해 피하고, 날아오는 투사체를 옆으로 비킨다 |
| **방어 반응** | 상대의 공격 준비 동작을 보고 패링 / 회피 / 반격 / 버티기 중 하나를 확률적으로 고른다 |
| **성향 반영** | 터닝포인트에서 바꾼 성향이 거리·공격성·회피 확률에 반영되고, 아래 상황 판단이 그 위에 더해진다 |

### 상황 판단 (0.38.0, 기존 판단 위에 얹는 층)

유닛마다 **전술 판단(TacticalMind)** 이 붙어, 매 0.25초 지금 얼마나 대담할지(신중 −1 ~ 저돌 +1)를 다시 정한다. 기존 시스템이 그대로 선택하고, 판단은 그 선택을 기울인다. 전투 난수를 쓰지 않아 같은 시드 전투는 그대로 재현된다.

| 요소 | 내용 |
| --- | --- |
| **기본 성향(역할)** | 모든 유닛은 근접형 · 대치형 · 후열 · 방황형 · 고정 중 하나를 반드시 가진다(은둔형은 후열, 비전투는 방황형으로 본다). 근접형은 저돌적으로, 대치형·후열은 신중하게 기운다. 엄호형(호위형)은 추가 성향 |
| **HP** | HP가 넉넉하면 저돌적으로, 낮으면 신중하게 기운다 |
| **전장 상황** | 살아 있는 아군과 적의 수·체력을 비교해 유리하면 저돌적으로, 불리하면 신중하게 기운다 |
| **신중할 때** | 거리를 두는 대치 움직임을 쓰고, 적이 나를 향해 휘두르는 동안은 공격을 미루고, 적의 공격이 빠진(후딜) 순간 바로 들어간다. 반격 대신 패링·회피를 더 고르고, 패링 타이밍 실수가 줄고 패링 성공률이 오른다 |
| **저돌적일 때** | 공격 기회를 더 빨리 잡고, 크게 기울면 돌진 성향처럼 틈만 나면 공격한다. 패링·회피 대신 반격을 더 고르고, 패링 성공률은 낮아진다 |
| **플레이어 성향과의 경계** | 상황 판단은 피해 배율, 반격 강화, 저돌적의 타깃 고정·후퇴 없음, 신중함의 선공 대기·추격 제한·대열 유지·측면 접근을 켜지 않는다. 이 효과들은 플레이어가 고른 성향에만 붙는다(0.42.0) |
| **공격 감지** | 보는 방향(240°)의 공격 준비 동작·투사체만 감지한다. 멀리서 다른 아군을 노리는 근접 공격은 무시한다. 나를 노리는 원거리 공격에는 HP가 넉넉하면 다가서며 패링으로 막고, HP가 낮으면 좌우로 비켜 회피한다 |
| **우선순위** | 기본은 캐릭터별 우선순위(가까운 적 중심). 엄호형은 주변 아군을 공격하는 적을, 신중할 때는 나를 공격하는 적을, 저돌적일 때는 사거리 근처의 빈사(HP 30% 미만) 적을 먼저 노린다. 치유 등 아군을 고르는 선택은 그대로 둔다 |

랜덤 3대3 30판 비교: 30판 모두 끝나고(교착 없음) 평균 전투 시간은 33.0초 → 32.3초. 체력이 넉넉한 근접 유닛의 첫 공격이 빨라졌다(전사 1:1 3.4초 → 2.2초).

랜덤 6대6 전투 40판 측정 결과:

### 13-2. 시각 스타일

- 어두운 남색 판타지 톤 + 금색 포인트. 버튼·카드는 역할별 색으로 구분한다.
  - 행동 카드: 따뜻한 회색 / 상점·모집 카드: 푸른 회색
  - 골드 가격: 금색 칩 / 토큰 가격: 파란 칩 / 살 수 없음: 반투명 + 빨간 글씨
- 배경: 그라데이션 위로 천천히 움직이는 빛 번짐과 떠오르는 입자. 패널은 부드러운 그림자로 띄운다.
- **UI 디자인 시스템**(0.46.0): 모든 화면이 세 가지 면만 쓴다. 공통 값은 `scripts/presentation/ui_style.gd`(`ArenaUI`)에 모여 있다.
  - **창**(대화상자·시트·결과 패널·터닝포인트 패널): 2px 테두리, 모서리 16, 깊은 그림자. 위쪽에 제목과 둥근 닫기 버튼, 아래에 가는 구분선.
  - **카드**(화면 안의 구역·목록 칸): 1px 선, 모서리 12, 그림자 없음. 눌리지 않는 정보 묶음이다.
  - **버튼**: 모서리 12, 밝은 테두리 + 아래쪽 4px 짙은 턱으로 솟아 보이고, 누르면 턱 위로 내려앉는다. 비활성은 평평하고 흐리다. 주 행동은 주황(진한 글씨), 일반 행동은 강철 파랑, 위험 행동은 빨강, 닫기·취소는 둥근 버튼. 탭은 어두운 홈 위에 선택된 칸만 솟는 세그먼트 방식.
  - 유닛·아이템·행동 카드처럼 눌리는 카드도 버튼과 같은 턱을 가진다. 가격 칩은 골드=청동, 토큰=남색 버튼.
  - 화면 위쪽 제목은 모두 굵은 제목 글꼴 19.
- 숫자·영문 대형 타이포는 Barlow Condensed, 그 밖의 모든 글자(한글·영문)는 **빗썸고딕 오리지날**(0.49.0, `assets/ui/fonts/bithumb_gothic_original.ttf`). 제목은 같은 글꼴을 살짝 굵게.

- 반복 재생도 끊기지 않게, 곡이 끝나기 2.5초 전부터 같은 곡의 처음과 교차 페이드한다.
- **타워 곡은 이어서 재생한다**: 전투·승리·패배 곡 등으로 바뀌면 서서히 줄며 멈추고, 다시 타워 곡이 나올 때 처음이 아니라 멈춘 지점부터 이어진다. 메인 화면에서 타워에 새로 들어갈 때만 처음부터 시작한다.
- **승리·패배 곡 다음 곡**(0.48.0): 승리·패배 곡에서 다른 곡(타워 곡 등)으로 넘어갈 때는 승리·패배 곡이 1.2초 동안 줄어 완전히 꺼진 뒤 다음 곡이 시작된다. 타워 곡은 멈췄던 지점부터 이어진다.
- **로딩 화면**(0.45.0): 타워 입장(메인 화면의 탑 줌 직후), 다음 층 입장(계단), 커스텀 전투 입장 때 어두운 그라데이션 배경 가운데에 작은 탑 아이콘(층마다 차례로 불이 켜지고 꼭대기 수정이 빛남)과 로딩바가 나온다. 들어오는 동안 진행 중인 음악이 0.9초 동안 서서히 줄며 끊기고, 로딩바가 차면(최소 1.2초) 다음 장면의 음악과 함께 걷힌다. 층 이동 때의 챕터 클리어 연출은 로딩이 끝난 뒤 나온다. UI 애니메이션을 끄면 로딩 화면 없이 바로 넘어간다. 다음 층 입장(계단) 로딩 중에는 타워 곡이 끊기지 않고 계속 흐른다(0.48.0).
- 구현: 자동 로드 `MusicPlayer`(`scripts/presentation/music_player.gd`, 재생기 2개 교차). 다른 코드는 `BackgroundMusic.play(&"menu" / &"tower" / &"battle" / &"victory" / &"defeat")`로 부르고, 로딩 화면(`scripts/presentation/loading_screen.gd`)은 `hold()`/`release()`로 음악을 멈췄다가 다음 곡을 튼다.
- 시작 화면(엔진 부트 스플래시): `assets/ui/boot_splash.png`(픽셀 로고), 화면을 꽉 채우도록 확대(Cover), 픽셀이 번지지 않게 필터 없음, 남는 여백 색은 이미지 아래쪽 라벤더(#DCD1F3).
- 로고 화면은 앱 실행 후 **3초**까지 유지된다. 엔진 로딩 화면과 똑같은 그림을 메인 화면 첫 프레임에 덮어 두므로 넘어가는 순간이 보이지 않고, 3초가 되면 0.7초 동안 사라지며 메인 화면 입장 연출이 시작된다(0.44.0).

### 15-2. 토론할 질문

1. **런 이후에 무엇이 남아야 하는가?** — 계정 레벨, 캐릭터 해금, 도감, 시작 길드 선택, 난이도 단계(어센션) 중 무엇이 이 게임에 맞을까?
2. **플레이어 개입의 양은 적당한가?** — 터닝포인트 12초/30초 간격, 초월 충전 속도, 전략카드 6종이 “관전 vs 조작”의 균형에 맞는가?
3. **캐릭터 시너지를 시스템으로 만들 것인가?** — 지금은 태그가 AI 행동에만 쓰인다. 같은 태그 2/4명 보너스 같은 시너지를 넣을지.
4. **토큰 경제** — 영입이 토큰에만 묶여 있다. 골드로도 영입할 수 있게 할지, 토큰 획득처를 늘릴지.
5. **보스의 정체성** — 일반 캐릭터의 강화판 대신 전용 보스(고유 패턴·페이즈·전용 맵)를 만들지.
6. **커스텀 전투의 확장** — 배치 공유 코드, 친구와 비동기 대결, 시나리오(퍼즐) 모드로 키울지.
7. **신규 캐릭터 방향** — 지금 32종 중 원거리·대치형이 많다. 다음 캐릭터는 어떤 역할이 비어 있는가?
8. **사운드와 피드백** — 타격감에 소리가 빠져 있다. 우선순위를 어디에 둘지.
