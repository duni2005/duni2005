## 1. 게임 개요

> **길드원을 모으고 전장에 배치한 뒤, 자동으로 벌어지는 전투의 결정적인 순간에 개입하며 15층 타워를 정복하는 자동전투 전략 로그라이트.**

| 항목 | 내용 |
| --- | --- |
| 장르 | 자동전투(오토배틀) + 로그라이트 + 길드 운영 |
| 플랫폼 | Android(세로 화면 우선), 웹 브라우저 미리보기 |
| 엔진 | Godot 4.6 (원작 HTML/JS 웹 게임을 이식 · 확장) |
| 시점 | 위에서 내려다보는 2D 아레나(800×800 논리 좌표) |
| 플레이어 역할 | 길드 **지휘관** — 유닛을 직접 조종하지 않고 준비 · 배치 · 개입을 결정한다 |
| 세계관 한 줄 | “두니 아레나의 승자가 망고를 얻을 것이다” — 망고를 향해 타워를 오르는 길드 이야기 |

**핵심 재미 세 가지**

1. **준비** — 어떤 길드원을 영입하고, 누구를 키우고, 어떤 장비를 주고, 어디에 세울지 고민한다.
2. **관전과 개입** — 41종 캐릭터가 각자 개성대로 싸우는 것을 보다가 터닝포인트 · 전략카드 · 초월 · 후퇴로 판을 뒤집는다.
3. **운영** — 유닛 HP · 플레이어 HP · 골드 · 토큰을 관리하며 15층까지 버틴다. 한 번 진다고 끝이 아니라 *손실을 안고 다시 도전*하는 구조다.

## 2. 게임 루프

### 2-1. 큰 루프 (한 판 = 한 “런”)

```
새 게임 / 이어하기
   └─▶ 타워 지도 (현재 층의 방 선택)
          ├─▶ 전투 방 ─▶ 배치 ─▶ 자동전투 + 개입 ─▶ 결과 · 정산
          ├─▶ 모집 / 상점 / 휴식 / 이벤트 방
          └─▶ 길드 관리 (유닛 · 인벤토리 · 강화)
   └─▶ 계단으로 다음 층 ─▶ 챕터 보스 ─▶ 다음 챕터 … ─▶ 15층 보스 처치 = 타워 정복
```

- **런 실패**: 플레이어 HP 0, 살아 있는 길드원 0명, 탐험 포기 — 셋 다 **타워 정복 실패**다.
  - 전투 중이나 정산에서 실패가 정해지면 패배 결과 없이 곧바로 실패 화면으로 넘어간다.
  - 탐험 포기는 경고창(“탐험을 포기하면 바로 타워 정복 실패로 처리되고, 지금까지의 진행은 이어할 수 없습니다”)에서 확정한다.
  - 실패 화면: 회색으로 가라앉는 화면, 기울어진 패널 위로 “타워 정복 실패”가 한 글자씩 무겁게 내려앉고 뒤에 대형 “FAILED”, 실패 사유, 떨어지는 회색 재(패배 곡). 2.2초 뒤 또는 탭하면 **결과 확인 / 메인화면 / 다시하기**.
    - 결과 확인: 실패 사유, 도달 챕터 · 층, 정복한 방 수, 남은 골드 · 토큰, 생존 길드원 수, 플레이어 HP.
    - 메인화면: 저장을 지우고 메인으로(이어하기 없음).
    - 다시하기: 그 자리에서 새 런(저장도 새 런으로 덮어쓴다).
- 길드원 한 명이 죽어도 런은 계속된다. 예비 길드원과 플레이어 HP가 남아 있으면 재도전할 수 있다.

### 2-2. 작은 루프 (전투 한 번)

```
배치 ─▶ 전투 시작 ─▶ 12초: 첫 터닝포인트 ─▶ 이후 30초마다 터닝포인트
            ├─ 초월 게이지가 차면 플레이어가 직접 조준해 발동
            └─ 20초 이후 조건을 만족하면 전체 후퇴 가능
─▶ 승리 / 패배 / 후퇴 ─▶ 결과 화면(손실 · 보상) ─▶ 지도로
```

## 3. 메인 화면과 게임 모드

| 모드 · 메뉴 | 내용 |
| --- | --- |
| **타워 입장** | 본편. 3챕터 15층 로그라이트 런. 진행 중인 저장이 없으면 바로 새 게임, 있으면 “두니 타워” 창에서 저장 요약(챕터 · 층 · HP · 골드 · 길드원 수 · 마지막 저장 시각)을 보고 **이어하기 / 새로하기**(교체 확인 한 번 더) |
| **커스텀 전투** | 원하는 캐릭터를 자유롭게 배치해 최대 4팀 + 개인전으로 싸워 보는 샌드박스 (12장) |
| **도감** | 유닛 · 아이템 · 전략카드 · 이벤트 · 피해태그 · 상태이상 · 보스 7개 탭 (13-1) |
| **설정** | 게임플레이 · 그래픽 · 소리 3개 탭 (13-6) |

- **배경**: 컷신풍 자연 풍경 — 맑은 하늘과 흘러가는 구름, 눈 덮인 먼 산맥, 능선 위 두니 타워(빛나는 꼭대기 수정), 계곡 마을, 탑으로 굽이치는 흙길, 숲 비탈, 앞쪽 수풀. 깊이가 다른 9개 레이어로 그려 화면 크기에 맞춰 탑을 중심으로 채운다(가로 화면은 탑 전체가 보이고 메뉴는 왼쪽).
- **로고**: “DUNI ARENA” 글자(ARENA 강조색, 얇은 외곽선 · 부드러운 그림자, 아래 금색 선과 마름모).
- **버튼**: 가로 직사각형 4개(타워 입장 강조 / 커스텀 전투 / 도감 / 설정), 아래 버전 표시.
- **연출**: 들어올 때 먼 레이어부터 떠오르며 카메라가 살짝 물러나고(2.4초) 메뉴가 뒤따라 나타난다. 타워에 들어갈 때 카메라가 탑으로 빨려 들어가며(1.5초) 하얗게 밝아진다. UI 애니메이션을 끄면 바로 넘어간다.
- **시작 화면**: 엔진 부트 스플래시(픽셀 로고, 화면을 채우도록 확대, 필터 없음)가 앱 실행 후 3초 유지되고 0.7초 동안 사라지며 메인 입장 연출이 시작된다.

## 4. 두니 타워 구조

### 4-1. 층과 챕터

| 항목 | 값 |
| --- | --- |
| 전체 | **3챕터 × 5층 = 15층** |
| 챕터 이름(임시) | 1 “무너진 회랑” · 2 “붉은 첨탑” · 3 “망고의 정상” |
| 층당 방 수 | `6 + ⌊층 번호(0부터) / 3⌋` → 1~3층 6개 … 13~15층 10개 |
| 층 이동 | 그 층 방의 절반(올림)을 완료하면 지도 무작위 위치에 **계단**이 열린다(챕터 마지막 층은 보스 처치도 필요). 계단으로 오르면 지나온 층의 방은 다시 들어갈 수 없다 |
| 층 정복 | 그 층의 **모든 방**을 완료하면 플레이어 HP 회복 + 추가 보상(길드 HP +20% / 토큰 +2 / 아이템 중 하나) |
| 방 발견 보상 | 처음 들어간 방마다 +50 G |

### 4-2. 층별 방 구성

- **1층(고정)** — 모집, 상점, 휴식, 전투, 이벤트, 전투 (튜토리얼 성격).
- **각 챕터 3번째 층** — 방 목록 가운데에 **미니보스** 방.
- **각 챕터 5번째 층** — **보스** 방과 휴식 · 이벤트 방만.
- **그 밖의 층** — 대략 전투 40%, 휴식 15%, 서비스(모집 · 상점 · 대장장이) 25%(1~4개), 나머지 이벤트.
  - 서비스 칸: 두 번째 칸은 50% 확률로 상점 대신 대장장이, 세 번째 이후는 모집 · 상점 · 대장장이 중 하나. 1층과 보스 층에는 대장장이가 없다.
- 방은 현재 층 안에서 **원하는 순서로** 고른다(길은 장식). 처음 보는 방은 종류가 “?”로 가려져 있다.

### 4-3. 적 구성 (전투 방)

| 항목 | 규칙 |
| --- | --- |
| 일반 전투 적 수 | `3 + ⌊층 × 0.7⌋ (+0~1)`, 최대 12 |
| 미니보스 방 | 엘리트 1 + 일반, 총 `2 + ⌊층 / 6⌋ (+0~1)`, 최대 6 |
| 보스 방 | 보스 1 + 엘리트 1 + 일반, 총 `4 + ⌊층 / 5⌋ (+0~1)`, 최대 7 |
| 적 평균 레벨 | `⌊층 × 1.6 + 0.5⌋` (개체마다 ±1 분배) |
| 적 기본 스탯 | 캐릭터 기본값 × 0.8에 레벨 성장(7-3) |
| 엘리트 배율 | 크기 1.5배 · HP ×2.5 · 공격력 ×1.65 · 방어 ×1.5 · 속도 ×1.08 |
| 보스 배율 | 크기 1.85배 · HP ×3.6 · 공격력 ×2.15 · 방어 ×2 · 속도 ×1.12 |
| 보스 후보 | 전사, 마법사, 수호자, 샷건, UFC 선수, 두비두밤, 챌런, 포식자, 폭탄 |
| 적 진형 | 전열 / 분산 / 쌍익 / 포위 / 밀집 중 무작위 |
| 역할 배분 | 전열(근접) · 원거리 · 지원 풀에서 고르게, 같은 캐릭터는 최대 2 |
| 초반 가중치 | 1~3층은 싼 캐릭터가 더 자주 나온다 |
| 처치 골드 | 적의 영입 토큰 ÷ 2에 비례 |

### 4-4. 지도와 탑 연출

- **지도**: 현재 층을 **위에서 내려다본 거대한 원형 탑**. 사암 성벽(왼쪽 위가 햇빛, 오른쪽 아래가 푸른 그림자), 챕터 색 원뿔 지붕의 망루 넷, 바람에 날리는 챕터 색 깃발, 안쪽 초원과 둥근 나무. 성벽 밖은 하늘(해, 햇살 줄기, 두 겹 구름, 떠 있는 섬, 그림자를 드리우는 새 떼, 정령 빛).
  - 방은 **둥근 돌 단** — 종류 색 바닥(전투 빨강 · 모집 보라 · 상점 파랑 · 대장장이 주황 · 휴식 초록 · 이벤트 청록, 미탐험은 안개 낀 회청색 “?”), 가운데 아이콘, 번호, 이름 리본, 클리어 체크. 보스 · 미니보스 방은 더 크고 가시 테두리와 빛, 계단 방은 빛나는 나선 계단. 방들은 모래길로 이어진다.
  - **카메라**: 한 손가락 드래그로 이동, 핀치 · 휠로 확대/축소(탑 전체 ~ 1.6배). 18px 넘게 끌면 방이 눌리지 않는다.
- **그림체**: 컷신(옆에서 본 탑)과 지도(위에서 본 탑)는 같은 **플랫 셀 스타일**과 팔레트를 쓴다(`TowerArt`) — 평면 색 면과 경계가 또렷한 그림자, 빛은 항상 왼쪽 위. 챕터 색: 1 청록 · 2 적색 · 3 금색.
- **연출 순서** (지도가 보이고 다른 연출이 없을 때 하나씩, 모두 건너뛸 수 없음)
  - **층 입장**(처음 보는 층): 탑 전체를 보여 주고 방이 번호 순서대로 빛 고리 · 먼지와 함께 솟아오른다. 미니보스 · 보스 방은 마지막에 빛기둥 · 룬 고리 · 이중 충격파와 함께. 길이 하나씩 그려지고 카메라가 확대되며 끝(약 3~4초).
  - **층 정복**(약 3.6초): 기울어진 패널, 위에서 떨어져 꽝 하고 내려앉는 금색 월계관 왕관(충격파 · 금빛 입자 · 빛살), 뒤에 흐르는 “CONQUEST”, “N층 정복”과 보상 칩.
  - **챕터 클리어**: 챕터 보스 처치 뒤 지도에서 챕터 클리어 컷신이 먼저 나온다.
  - **개방**(약 3.2초): 탑이 흔들리고 카메라가 계단 쪽으로 움직이며 금빛 기둥이 모였다가 계단 방이 터지듯 열리고 길이 그려진다. “FLOOR N · OPEN / N층 개방”(다음 챕터면 “챕터 N 개방”과 챕터명). 이 컷신 전에는 계단이 닫혀 있다.
- **탑 컷신**: 새 게임 시작 시 하늘로 뻗은 탑 전경(배경 레이어만 옆으로 흐르고, 떠 있는 섬과 폭포, 정령 빛, 소개되는 챕터의 창문이 아래층부터 금빛으로 켜짐) → 빠른 확대 → 1챕터와 챕터 제목. 이어하기는 챕터 제목 장면만. 탭하면 건너뛴다.

## 5. 방 종류

| 방 | 하는 일 | 핵심 규칙 |
| --- | --- | --- |
| **전투** | 적을 모두 쓰러뜨린다 | 보상 `350 + 50 × 층` G. 이겨도 유닛 HP는 회복되지 않는다 |

## 6. 전투 시스템

### 6-1. 기본

- **800×800 아레나**에서 아군(왼쪽 배치 구역)과 적(오른쪽)이 자동으로 싸운다.
- 유닛의 **이동 · 타깃 선택 · 기본공격 · 방어 반응 · 궁극기**는 모두 AI가 한다(11장).
- 플레이어는 **배치 → 터닝포인트(성향 · 전략카드) → 초월 → 후퇴**로 개입한다.
- 한 전투의 **출정** 인원은 기본 3명, 길드 확장으로 최대 8명(7-4). 배치 화면 도구줄에 “출정 현재/최대”.
- 배속 1× / 2× / 4×(시각 효과도 같은 배속), 일시정지 가능.
- 아레나 바닥: 차분한 2~3톤 풀밭, 구불구불한 흙길, 디딤돌 · 물웅덩이 · 꽃, 가장자리의 흔들리는 그늘과 룬 석주 그림자. 덤불 울타리 너머에는 바위 · 돌기둥 · 석상 · 나무가 무리 지어 있고, 배치 · 전투 화면에서는 이 풍경이 경기장 밖 화면 전체에 비친다.

### 6-2. 공격과 판정

| 요소 | 설명 |
| --- | --- |
| 근접 공격 | 부채꼴 범위 판정. 휘두르는 모션이 실제 판정과 같은 타이밍 |
| 투사체 | 화살 · 마법탄 · 포탄 등 실제로 날아가는 물체. 관통 · 튕김이 있는 것도 있다 |
| 상쇄(Clash) | 공격끼리 부딪치면 서로 지워진다 |
| 패링 | 근접 공격을 정확한 타이밍에 막아 무효화하고 반격 기회를 만든다(전사가 특히 강함). 성공률 = 방어력 ÷ 상대 공격 세기(주 피해 스탯 × 공격력%) |
| 회피 | 신중함 성향 · 일부 캐릭터는 확률적으로 구르기 · 회피 |
| 넉백 | 강한 공격은 상대를 밀어낸다. 일부 넉백은 벽 · 유닛과 부딪히면 기절을 건다 |
| 치명타 | 기본 확률 0%, 치명타 피해량 150% |

### 6-3. 스탯과 피해 계산

커스텀 전투와 두니 타워에 같은 규칙이 적용된다. 피해 수치는 `scripts/unit_stat_table.gd`, 최대 HP · 이동속도 · 사거리 · 공격 간격은 캐릭터 데이터(`data/*.tres`), 밸런스 배율은 `scripts/unit_balance.gd`에 있다.

**기본 스탯**

| 스탯 | 설명 |
| --- | --- |
| 최대 HP | |
| 방어력 | 모든 피해를 줄인다 |
| 물리 방어력 / 마법 방어력 | 그 유형의 피해만 추가로 줄인다. 기본 0, 음수 가능 |
| 공격력 | 모든 피해에 곱하는 배율, 기본 100%. 아이템, 포식자의 엄니 처치 성장, 적 엘리트 · 보스 배율, 성향(저돌적 ×1.1, 엄호 ×0.85), 전략카드 강화가 여기에 곱해진다 |
| 물리 피해 / 마법 피해 | 유닛마다 정해진 피해 스탯. 각 피해 인스턴스가 자기 유형의 값을 계수로 쓴다 |
| 이동속도 · 사거리 | |
| 공격속도 | 1 ÷ 공격 간격. 배율(기본 100%)이 오르면 **공격 사이 대기**(쿨타임, 공격 후 물러나기, 다음 공격 결심, 조준 지연)와 **공격 동작**(준비 · 발동 · 회복)이 모두 그만큼 짧아지고, 재장전도 빨라진다 |
| 치명타 확률 / 치명타 피해량 | 기본 0% / 150% |

**특수 스탯** (모두 %)

| 스탯 | 기본값 | 적용 |
| --- | --- | --- |
| 주는 치유량 / 받는 치유량 | 100% | 이 유닛이 주는 / 받는 치유 |
| 궁극기 피해량 | 100% | 궁극기 피해 인스턴스 |
| 궁극기 충전률 | 100% | 궁극기 게이지 충전 |
| 속성 피해 | 100% | 속성 태그가 하나라도 있는 피해 |
| 속성별 보너스 | 0% | 얼음 · 화염 · 맹독 · 바람 · 빛 · 어둠 · 번개 |
| 태그별 보너스 | 0% | 폭발 · 범위 · 투사체 · 지속 · 근접공격 |

**피해 인스턴스와 태그**: 모든 피해는 **물리 또는 마법 중 정확히 하나**의 유형과 0개 이상의 태그(속성 7종 + 폭발 · 범위 · 투사체 · 지속 · 근접공격)를 가진다. 한 유닛이 유형을 섞어 쓸 수 있다(예: 탱크 포탄은 물리, 화염 지대는 마법). 캐릭터별 정의는 9-7 표.

| 태그 | 붙는 피해 |
| --- | --- |
| 폭발 | 터지는 공격 |
| 범위 | 여러 적을 한 번에 맞히는 공격 |
| 투사체 | 날아가 맞히는 공격 |
| 지속 | 시간을 두고 반복해서 맞히는 공격 |
| 근접공격 | 가까이 붙어 베고 찌르고 치는 공격(근접 기본공격과 근접 궁극기) |

```
원피해  = 기본값 + (물리 피해 또는 마법 피해) × 계수
피해    = 원피해 × 공격력%
          × (1 + 맞는 속성 · 태그 보너스의 합)
          × 속성 피해%        (속성 태그가 있을 때만)
          × 치명타 피해량%    (치명타일 때만)
          × 궁극기 피해량%    (궁극기 피해일 때만)
방어    = 방어력 + (물리 방어력 또는 마법 방어력)
최종    = 피해 × 100 / (100 + 방어)          방어 ≥ 0
최종    = 피해 × (2 − 100 / (100 − 방어))    방어 < 0
```

- 100은 조정 상수(`UnitStatTable.MITIGATION`)다. 방어 100이면 피해 절반, 방어 −100이면 1.5배.
- 그 뒤에 성향 배율(저돌적 받는 피해 ×1.2 · 신중함 ×0.85), 저주 · 목표 같은 받는 피해 변화, 수호자 0.8배, 60초 이후 피해 가속, 고유 방어 · 패링 절반 등이 이어진다.
- **반사 · 공유 · 분배 피해**(금간 거울 반사, 자석 공유, 인형술사 분담)는 원래 피해의 유형 · 태그를 유지하되 **받는 쪽의 방어만** 적용한다.
- **상태 이상 피해**(화상 · 맹독 · 침식 · 동상 추가 피해 · 연쇄충격 · 속삭임 폭발 등)는 패링 · 회피 · 치명타가 없고 작은 색 숫자로 표시된다.

### 6-4. 속성 효과

속성 태그가 붙은 피해는 피해 외에 아래 효과를 남긴다. 수치는 `scripts/element_effects.gd`(`ElementEffects`)에 모여 있다. 스택 · 표식 · 타이머는 전투가 끝나면 사라진다.

| 속성 | 부여 | 효과 |
| --- | --- | --- |
| 🔥 화염 | 화염 공격 시 50% 확률로 화염 2스택(최대 10) | 0.5초마다 1스택을 태워 마법 지속 피해 4. 불붙은 유닛은 90 거리 안의 **자기 아군**에게 화염 피해 2(스택은 옮지 않음) |
| ☠️ 맹독 | 맹독 공격 시 50% 확률로 맹독 1스택 | 스택은 전투 내내 남고 매초 스택당 마법 지속 피해 1. 중독된 유닛은 주는 · 받는 치유 −40% |
| ❄️ 얼음 | 얼음 공격 시 50% 확률로 빙결 1스택(4초간 새로 안 쌓이면 녹음) | 10스택이면 4초 **빙결**(기절). 풀리면 4초 **동상**: 받는 피해 +10%, 동상 중 빙결을 받으면 스택 대신 마법 추가 피해 5 |
| ⚡ 번개 | 번개 피해를 줄 때마다 감전 1스택 | 5스택이면 2초 기절. **연쇄충격**: 준 피해의 60%를 200 거리 안 가장 가까운 다른 적에게 튕기고, 튈 때마다 직전의 60%로 최대 5회 |
| 🌪️ 바람 | 바람 공격을 할 때마다 공격자가 기류 1스택(최대 10) | 스택당 공격속도 +5%, 바람 피해 +3%. 직접 공격으로 HP가 깎이면 0. **역풍**: 맞은 적은 2초간 이동속도 −30%, 공격속도 −20% |
| ✨ 빛 | 빛 피해를 줄 때 | **순환**: 피해의 10%만큼 공격자 주변 160 거리 아군(자신 포함) 회복. **광휘 표식**: 다른 유닛이 직접 공격으로 터뜨리면 터뜨린 유닛이 최대 HP 5% 회복 |
| 🌑 어둠 | 어둠 공격에 맞을 때 | **침식** 2초: 이동 외 행동마다 마법 지속 피해 6, 받는 치명타 피해 +25%. **암흑 표식**: 다른 유닛이 직접 공격으로 터뜨리면 그 공격 피해 +20% |

- **직접 공격**: 지속 태그가 없는 공격이 실제로 맞은 것. 지속 · 상태 이상 피해, 연쇄충격, 충돌은 직접 공격이 아니다.
- **유닛 고유 부여**: 확률 대신 자기 규칙으로 쌓는 유닛이 있다 — 빙결술사(수정 1스택, 폭풍 틱당 2스택), 빙하 골렘(냉기 1스택 확정), 불의 검사(베기마다 화염 5스택). 번개 마법사의 연쇄 번개는 스스로 튀므로 연쇄충격을 따로 일으키지 않고, 대방전은 감전 2스택을 준다.

| 매혹 | 시전자를 향해 천천히(이동속도 45%) 걸어가며 공격 · 궁극기 불가, 하던 공격 · 궁극기 준비도 끊김. 시전자가 쓰러지면 풀림 (속삭이는 자, 5초) |
| 속삭임 | 바늘 스택, 3스택이 되면 터지며 최대 HP 5% 추가 피해 |

전투 밖(배치 화면)의 아군 · 대기 유닛과 적은 전투 사이에 이어지는 상태(포식 성장, 보호막, 남은 저주 등)와 아이템 효과를 보여 준다.

### 6-6. 게이지

| 게이지 | 쓰는 주체 | 차는 방법 | 설명 |
| --- | --- | --- | --- |
| **궁극기** | AI | 시간 경과 + 피해를 주고받을 때 | 가득 차도 AI가 상황(사거리 · 대상 · 위험)을 보고 쓴다. HP바 아래 보라색 바, 가득 차면 금색으로 반짝임 |
| **초월** | 플레이어 | 피해를 주고받을 때 | 준비된 아군 카드를 **길게 눌러 조준 → 끌어 놓아 발동**. 전투가 멈추고 강한 방향성 공격(초월 · 검격: 60 + 주 피해의 500%, 범위, 강한 넉백)이 나간다 |

### 6-7. 터닝포인트(TP)와 성향

- **12초에 첫 TP**, 이후 **30초 간격**. 2초간 감속 → 정지, 정지 상태에서 **최대 40초** 동안 전략을 고른다.
- 할 수 있는 것: 아군 **성향** 변경, **전략카드** 사용(10-5), 전투 재개, 후퇴.
- 카드 줄에는 **지금 쓸 수 있는 카드만** 나온다. 써 버린 일회성 카드는 사라지고, 쿨타임 중이거나 이번 층에 이미 쓴 카드는 인벤토리에 “대기”로 남는다.
- 필드 조작: 두 손가락 확대 · 축소, 확대 상태에서 한 손가락 드래그로 시점 이동, 필드의 아군을 누르면 하단 유닛도 선택된다.

| 성향 | 요약 |
| --- | --- |
| 기본 | 캐릭터 고유 판단을 따른다. 상황 판단(11-2)에 따라 두 성향의 움직임이 섞여 보인다 |
| 저돌적 | 가장 가까운 적에게 곧장 붙어 쉬지 않고 친다. 주는 피해 ×1.1, 받는 피해 ×1.2 |
| 신중함 | 측면으로 돌아 들어가 치고 빠진다. 받는 피해 ×0.85, 막아 낸 뒤 반격 강화 |
| 엄호 | 보호할 아군 곁을 지키며 날아오는 공격을 몸으로 막는다. 공격력 ×0.85 |

성향 상세 (플레이어가 고른 성향에서만 켜지고 상황 판단으로는 켜지지 않는다. 수치는 `scripts/stance_rules.gd`):

| | 저돌적 | 신중함 |
| --- | --- | --- |
| 이득 | 주는 피해 ×1.1 | 받는 피해 ×0.85, 반격 강화 |
| 손해 | 받는 피해 ×1.2 | 공격 가동률이 낮다(선공 대기, 공격 지연 ×1.15, 다음 공격 대기 ×1.25) |
| 방어 반응 | 패링 −12%p, 회피 −7%p, 공격 읽기 1.45배 느림, 투사체 감지 50% · 0.28초 | 패링 +9%p · 성공률 ×1.25 · 타이밍 실수 15%, 회피 +5%p, 공격 읽기 0.72배, 투사체 감지 93% · 0.56초, 피격 시 10% 자체 회피(3초 재사용) |
| 이동 | 타깃을 향해 직선으로 최단 접근 | 타깃 주위를 곡선으로 돌며 정면을 피해 측면으로 |
| 공격 후 | 물러나지 않고 바로 다음 공격 | 한 번 치고 1.1~1.7초 뒤로 빠진다 |
| 첫 접촉 | 사거리에 들어오면 0~0.08초 안에 공격 | 상대가 먼저 휘두르길 기다렸다가(최대 4초) 후딜에 들어간다 |
| 타깃 | 가장 가까운 적, 죽기 전까지 고정(도발 예외) | 나를 공격하는 가까운 적 → 고립된 적 |
| 추격 | 끝까지 쫓는다 | 타깃이 사거리 +90 밖이면 마지막 자리로 돌아가 최대 3초 기다린다 |
| 아군과의 거리 | 신경 쓰지 않는다 | 가장 가까운 아군과 120 이상 벌어지면 돌아오고, 적 2명 이상이 230 안에 있는 자리는 피한다 |
| 원거리 유닛 | 공격하면서 사거리 절반(최대 110)까지 다가간다 | 쏘고 물러나고 다시 쏜다 |

- **반격 강화(신중함)**: 회피 · 패링에 성공하면 3초 안의 다음 공격 +50%(막아 낸 공격이 저돌적 유닛의 것이면 +100%). 준비된 동안 HP바 오른쪽에 금색 마름모가 깜빡인다.
- **표시**: HP바 왼쪽에 성향 아이콘(저돌적 주황 꺾쇠, 신중함 청록 방패, 엄호 파란 고리). 상황 판단이 “돌격” · “신중”으로 바뀌는 순간에만 머리 위에 글자가 0.9초 떠오른다.

### 6-8. 적의 특수전략

- 적은 TP마다 상황에 따라 **확률적으로** 특수전략을 준비한다(`EnemyStrategyPlanner`).
  - **위험도** = 진행도(1층 0 → 15층 1) + 방 가중치(미니보스 +0.15, 챕터 보스 +0.3).
  - 한 명이 행동할 확률 = (0.12 + 0.55 × 위험도) × 적 수 보정(√(3 / 적 수), 0.55~1.5) + 등급 보정(엘리트 +0.1, 보스 +0.25), 최대 90%.
  - 등급(일반 / 위험 / 고위험)을 먼저 고른다(가중치 일반 1, 위험 0.2 + 0.8 × 위험도, 고위험 (위험도 − 0.3) × 1.5). 고위험은 위험도 0.3 이상에서만, TP 하나에 최대 (0.3 이상 1 + 0.9 이상 1 + 챕터 보스 방 1)개.
- TP 동안 준비 중인 전략이 적 머리 위 **배지**로 보인다(위험 주황 “!”, 고위험 붉게 맥박치는 “!!”). 배지를 누르면 상세 카드, 한 번 더 누르면 유닛 설명창. 공격 · 이동 범위나 경로가 바닥에 표시된다.
- TP가 끝나면 바로 사용된다. 예고가 있는 공격은 그 사이 기절하면 취소되고, 도발에 걸린 적은 이동 · 강타 · 가르기가 끊긴다.

| 특수전략 | 등급 | 고르는 상황 | 효과 (1층 → 15층) |
| --- | --- | --- | --- |
| 회복 | 일반 | HP 65% 미만, 낮을수록 자주 | 최대 HP **20% → 30%** 회복 |
| 이동 | 일반 | 근접형이 멀리 있을 때 | 표시된 경로로 최대 320 빠르게 이동 |
| 회피 | 일반 | 원거리형이 붙잡혔을 때, HP 50% 미만인데 적이 가까울 때 | 가장 안전한 곳으로 최대 320 빠르게 이동 |
| 참격 | 일반 | 대상이 260 안 | 대상 쪽 최대 140 앞의 원(반경 85)에 0.6초 예고 뒤 주 피해 **×1.3 → ×1.9** |
| 충전 | 일반 | 궁극기 게이지 80% 미만 | 궁극기 **20% → 30%** 충전 |
| 강타 | 위험 | 적이 바로 앞에 있을 때 | 앞쪽 부채꼴(반경 150, ±55°)에 0.6초 예고 뒤 주 피해 **×2 → ×3** + 2초 기절 |
| 가르기 | 위험 | 대상이 110~340 거리 | 대상 쪽으로 최대 380 대시, 경로(폭 64)의 적에게 주 피해 **×1.5 → ×2.3** |
| 과충전 | 위험 | 4층 이상, 층이 오를수록 자주 | 즉시 궁극기 사용(궁극기 없는 샷건은 8초 강화) |
| 휩쓸어 모으기 | 고위험 | 주변 원(반경 210) 안에 아군이 있을 때, 많을수록 자주 | 1초 예고 뒤 원 안 모두에게 주 피해 **×2.4 → ×3.4** + 적 앞 한 점으로 끌어모음 |

### 6-9. 후퇴 · 승패 · 손실

- **후퇴**: 전투 **20초 이후** 조건을 만족하면 전체 후퇴. 방은 미클리어로 남고 **적의 남은 HP · 사망 상태가 유지**되어 다시 도전할 수 있다. 패배 페널티는 없지만 이미 죽은 길드원의 손실은 그대로다.

| 상황 | 결과 |
| --- | --- |
| 승리 | 방 보상 골드(+ 황금 토큰 효과). 유닛 HP 회복은 없다 |
| 길드원 사망 | 플레이어 HP가 **그 캐릭터 기본 가치의 5%**만큼 감소(예: 전사 100 G → −5) |
| 패배 | 추가로 플레이어 HP **−20** |

### 6-10. 처치 기록과 연속 킬

- **킬 로그**: 필드 위 상태줄에 “처치한 유닛 / 쓰러진 유닛” 캡슐이 3초간 표시된다(양끝 팀 색, 새 처치는 위에서 밀고 들어온다).
- **연속 킬**: 한 유닛이 6초 안에 연달아 처치하면 **더블 → 트리플 → 쿼드라 → 펜타 → 헥사 킬** 리본 배너(2.6초, 처치 유닛 초상 · 이름, 처치 수만큼 마름모 눈금). 다른 유닛의 연속 킬은 차례를 기다린다.
- **슬라임**: 같은 슬라임에서 나뉜 개체가 모두 쓰러질 때, 마지막 개체를 쓰러뜨린 처치만 연속 킬에 센다.
- 필드 유닛 테두리는 **팀 색**(아군 파랑 / 적 빨강, 커스텀은 팀별 색). HP바(팀 색)와 궁극기 바는 화면이 작아져도 일정 크기 이상으로 그린다.

## 7. 길드원 성장과 관리

### 7-1. 길드원은 “개인”이다

같은 캐릭터를 두 번 영입해도 합쳐지지 않는다. 각 길드원은 자기만의 **HP · 레벨 · 성급 · 장비**를 가지며 `#1, #2 …` 번호로 구분한다.

### 7-2. 초기 길드 (새 런)

전사 2명, 궁수 1명, 힐러 1명 · 골드 1,200 · 토큰 5 · 플레이어 HP 100 · 전략카드 망고주스 1, 전투회피 1, 보호막 2.

### 7-3. 경험치와 레벨

레벨은 골드로 **경험치(EXP)를 사서** 올린다. 길드 관리 “강화” 탭에서 100 EXP 묶음 단위로 산다.

- **EXP +100**: 100 EXP(100 G)를 산다.
- **즉시 레벨업**: 다음 레벨까지 필요한 만큼 묶음을 자동 구매(`⌈남은 EXP / 100⌉ × 100 G`). 넘치는 경험치는 남는다.

| 항목 | 값 |
| --- | --- |
| 환율 | 1 G = 1 EXP |
| 레벨 L → L+1 필요 EXP | `80 + 20 × L` |
| Lv.L까지 누적 EXP | `80L + 10L(L−1)` (Lv.10 = 1,700) |
| 레벨 상한 | 없음 |
| 레벨당 성장 | 최대 HP +12%, 물리 · 마법 피해 +8%, 방어력 +8%, 이동속도 +2% (기본값 대비 누적, 물리 · 마법 방어력은 고정) |

### 7-4. 길드 확장

강화 탭은 “유닛 강화 | 길드 성장” 두 화면이다. **길드 성장**에 승급과 길드 확장 세 줄이 있고 모두 골드로 산다.

**출정 가능 수** (기본 3명)

| 단계 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 출정 최대 | 3명 | 4명 | 5명 | 6명 | 7명 | 8명 |
| 다음 단계 비용 | 500 G | 800 G | 1,200 G | 1,700 G | 2,300 G | — |

**길드 인원 한도** (기본 10명, 사망한 길드원도 포함). 한도가 차면 모집할 수 없고, 온천 복권의 “유닛” 보상은 토큰 3개로 바뀐다.

| 단계 | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| 인원 한도 | 10명 | 12명 | 14명 | 16명 | 18명 |
| 다음 단계 비용 | 300 G | 500 G | 800 G | 1,200 G | — |

**높은 유닛 영입 확률** (Lv.1~5, 비용 400 / 700 / 1,100 / 1,600 G). 후보 칸마다 이 표대로 영입 가격(등급)을 정한 뒤 그 가격의 캐릭터 중 하나를 균등하게 뽑는다(한 방에 같은 캐릭터 중복 없음).

| 단계 | ◆ 1토큰 | ◆◆ 2토큰 | ◆◆◆ 3토큰 | ◆◆◆◆ 4토큰 | ◆◆◆◆◆ 5토큰 |
| --- | --- | --- | --- | --- | --- |
| Lv.1 (기본) | 40% | 30% | 18% | 9% | 3% |
| Lv.2 | 32% | 30% | 22% | 12% | 4% |
| Lv.3 | 25% | 28% | 25% | 16% | 6% |
| Lv.4 | 18% | 25% | 28% | 20% | 9% |
| Lv.5 | 12% | 20% | 30% | 25% | 13% |

### 7-5. 성급(★) 승급

- 길드 성장 화면의 **승급** 버튼으로 승급 창을 연다.
- 조건: **생존한 같은 캐릭터 · 같은 성급 유닛 3명**(레벨 조건 없음). 성급은 ★2까지.
- **주 유닛 1명 + 재료 2명**을 고른다. 주 유닛이 ★ +1, 재료는 소모된다. 결과 수치는 승급 연출에서 공개한다.
- **경험치**: 세 유닛 누적 EXP 합 + 승급 보너스 EXP 300.
- **스탯**: ★ 자체의 스탯 보너스는 없다. 장비 칸만 기본 2 → ★1 3칸 → ★2 4칸.
- **HP**: 세 유닛 현재 HP의 평균(새 최대 HP를 넘으면 맞춤).
- **장비**: 주 유닛 장비는 그대로, 재료 장비를 빈 칸에 **고대 > 전설 > 영웅 > 희귀 > 일반** 순으로 넣고, 남으면 인벤토리로.

### 7-6. 장비 · HP · 사망

- 장비는 칸 수만큼 장착하며 **자유롭게 해제할 수 없다**(회수는 소모품 “재각인”). 아이템은 조합되지 않는다(10-1).
- 유닛 HP는 방을 옮겨도 이어진다. 전투에서 이겨도 회복되지 않으므로 휴식 · 온천 · 보물상자 · 층 정복 보상 · 전략카드 · 힐러로 관리한다.
- 죽은 길드원은 목록에 남는다(HP 0, 배치 불가). 휴식소 · 묘목 · 토큰 상점의 부활로 되살린다.

## 9. 캐릭터 (41종)

원작 웹 게임의 26종(0~25번)에 Godot 버전 신규 15종(26~40번)을 더해 41종이다. 모든 캐릭터는 커스텀 전투와 타워(모집 · 적 등장)에 모두 나온다.

### 9-1. 역할 태그

모든 유닛은 기본 성향 **근접형 / 대치형 / 후열 / 방황형 / 고정** 중 하나를 가지며, 그 위에 다른 태그를 더 가질 수 있다(데이터 이름 돌격형 · 호위형 · 방황은 화면에서 근접형 · 엄호형 · 방황형).

| 태그 | 의미 |
| --- | --- |
| 근접형 | 적에게 다가가 싸운다. 저돌적인 성향이 강하다. 다른 기본 성향이 없으면 근접형 |
| 대치형 | 사거리에 맞춰 거리를 두고 싸운다. 신중한 성향이 강하다 |
| 후열 | 아군 뒤에서 싸우고, 적이 다가오면 자리를 벗어난다(은둔형 포함) |
| 방황형 | 전장을 자유롭게 돌아다닌다(비전투 포함) |
| 고정 | 걸어서 움직이지 않는다 |
| 엄호형 | 아군 곁에서 움직이며 아군을 공격하는 적을 우선 노린다 |
| 의존형 | 특정 아군을 중심으로 움직인다 |
| 회피형 · 신중형 · 기습형 · 은둔형 · 약자멸시 · 폴짝 · 비전투 | 캐릭터 고유 성격(회피 확률, 은신, 약한 적 우선, 점프 이동, 전투 불참 등) |

### 9-2. 희귀도

캐릭터의 **영입 가격(토큰 1~5개)이 곧 희귀도**다.

| 등급 | 영입 | 수 | 캐릭터 |
|---|---|---|---|
| ◆ 일반 | 1 토큰 | 9종 | 전사, 궁수, 마법사, 암살자, 수호자, 힐러, 샷건, 광신도, 배달부 |
| ◆◆ 고급 | 2 토큰 | 9종 | 대구경 저격수, 가위바위보 마스터, UFC 선수, 두비두밤, 챌런, 폭탄, 검객, 기관총, 말뚝 |
| ◆◆◆ 희귀 | 3 토큰 | 9종 | 성기사, 금간 거울, 개구리, 굴절, 빙결술사, 화염방사기, 석궁, 슬라임, 속삭이는 자 |
| ◆◆◆◆ 영웅 | 4 토큰 | 10종 | 소형 위성, 히어로, 번개 마법사, 은하, 인형술사, 자석, 그리핀, 앵무새, 빙하 골렘, 불의 검사 |
| ◆◆◆◆◆ 전설 | 5 토큰 | 4종 | 포식자, 탱크, 기관사, 역병 |

- **표시**: 유닛 카드(모집 · 길드 목록 · 배치 · 승급 · 부활 · 커스텀 목록)에 등급 색 **윗줄**, 고급부터 등급 색 테두리와 은은한 색 번짐, 영웅부터 두꺼운 테두리, 전설은 테두리를 따라 금빛이 돈다. ◆ 개수(= 토큰 수)로도 보인다. 유닛 설명창은 초상화 고리와 빛이 등급 색이고 이름 옆에 등급 칩.
- 등급 색: 일반 회색 · 고급 초록 · 희귀 파랑 · 영웅 보라 · 전설 금색.
- 모집 확률은 7-4 “높은 유닛 영입 확률” 표.

### 9-3. 밸런스 배율

#### 9-5-1. 앵무새의 흉내

- 가장 가까운 적의 궁극기 게이지를 50 깎고(부족해도 사용) 그 적의 궁극기를 앵무새가 쓴다. 피해 표 · 효과는 원래 궁극기를 따르고, 피해 스탯은 앵무새의 것.
- 흉내 낸 뒤 8초간 그 궁극기에 딸린 효과(폭풍 이동, 반사 · 수호 창, 안개 등)가 앵무새에게 이어진다.
- 모든 유닛을 흉내 낼 수 있고, 앵무새에 맞게 바꾼 경우:

| 대상 | 앵무새가 하는 것 |
| --- | --- |

| 샷건 · 굴절 (궁극기 없음) | 그 유닛의 기본공격을 바로 쏜다 |
| 근접 궁극기 (전사, UFC, 두비두밤, 포식자, 검객, 말뚝, 빙하 골렘) | 먼저 대상 앞으로 날아간 뒤 사용 |

| 개구리 | 대상을 삼켰다 뱉는다 |

| 다른 앵무새 | 그 앵무새가 마지막으로 흉내 낸 궁극기(흉내 낸 적이 없으면 건너뜀) |

## 10. 아이템과 전략카드

> 0.94 개편: 아이템은 **조합하지 않는다.** 희귀도별 고유 아이템을 **보상으로 얻는다.** 모든 확률 · 가격 · 수치는 `ItemTuning`(scripts/item_tuning.gd) 한 곳에 모여 있다.

### 10-1. 희귀도

| 등급 | 색 | 카드 테두리 | 얻는 법 |
| --- | --- | --- | --- |
| **일반** (12종 + 재각인) | 회색 | 가는 테두리 | 전투 보상 · 상점 · 이벤트 |
| **희귀** (8종) | 파랑 | 가는 테두리 | 전투 · 미니보스 보상 · 상점 · 이벤트 |
| **영웅** (3종) | 보라 | 두꺼운 테두리 | 전투 · 미니보스 · 보스 보상 · 층 정복 · 상점 |
| **전설** (6종) | 금 | 두꺼운 테두리 + 테두리를 따라 도는 금빛 | 같은 곳 · **한 런에 같은 전설은 하나만** |
| **고대** (3종) | 적홍 | 두꺼운 테두리 + 적홍빛 | 탑에서는 나오지 않음(커스텀 전투에서만 선택) · **유닛당 1개** |

- 아이템 카드 · 인벤토리 · 상점 · 보상 · 도감에서 등급 색 테두리로 구분한다. 표시 방식은 유닛 희귀도와 같다.
- 이미 가진 전설(장착 여부 무관)은 보상 · 상점 후보에서 빠진다.
- 조합은 없다. 같은 유닛에 일반 아이템 둘을 끼워도 각자 한 칸씩 차지한다.
- 장착 고정과 소모품 **재각인**(120 G, 일반 등급 소모품: 선택한 유닛의 장비를 모두 회수)은 그대로다.
- 승급하면 재료 유닛의 장비가 리더의 빈 칸으로 **고대 > 전설 > 영웅 > 희귀 > 일반** 순서로 옮겨진다.
- 예전 버전의 아이템 10종은 저장 호환을 위해 “구형” 등급으로 남아 있지만 더 이상 나오지 않는다.

| 보물상자 “숨은 보물” · 온천 복권 · 토큰 상점 | 공용 표로 뽑는 무작위 아이템 |
| 도박꾼의 방 룰렛 “아이템” 칸 | 일반 80% · 희귀 17% · 영웅 2% · 전설 1% |
| 고대 | 탑에서는 나오지 않는다 |

- 보상 선택은 방에 저장된다. 고르거나 건너뛰기 전에는 지도로 돌아갈 수 없고, 선택 전에 저장 · 종료했다면 이어하기 직후 같은 3장을 다시 고른다.

**상점**

- 방에 처음 들어갈 때 아이템 3~5개(개수도 무작위)를 공용 표로 뽑아 진열하고, 재방문해도 유지한다. 전략카드 진열은 예전과 같다(같은 카드 여러 장은 한 카드에 “×2”로 표시).
- 가격: 일반은 아이템별 가격(120~160 G), 희귀 300 G, 영웅 550 G, 전설 900 G.

### 10-4. 대장장이 (강화 · 판매)

- **강화**: 희귀 · 영웅 · 전설 아이템, 골드로 최대 +5, 성공률 100%. 장착 중에도 강화할 수 있고 승급으로 옮겨져도 유지된다. 고대는 강화할 수 없다.

| 단계 | 비용 | 누적 | 스탯 증가 |
| --- | --- | --- | --- |
| +1 | 200 G | 200 G | +10% |
| +2 | 330 G | 530 G | +20% |
| +3 | 530 G | 1,060 G | +30% |
| +4 | 800 G | 1,860 G | +40% |
| +5 | 1,200 G | 3,060 G | +60%, 이름 금빛 |

  - 증가율은 아이템이 올려 주는 스탯 수치에 곱해진다(예: 군주의 검 공격력 +40% → +5에서 +64%). 특수 능력과 승리 골드는 그대로.
- **판매**: 장착하지 않은 일반 · 희귀 아이템, 상점 가격의 50%.
- 교환 탭은 없어졌다.

### 10-5. 화면

- **보상 선택**: 전투 결과 화면 아래에 아이템 카드 3장(등급 색 테두리 · 이름 · 효과 · 등급)과 건너뛰기. 카드는 차례로 뒤집히며 등장하고, 영웅 이상은 등장 순간 등급 색 빛이 터진다. 전설은 짧은 금빛 연출(빛줄기 · 불꽃)이 더해진다.
- **커스텀 전투 아이템 선택**: 일반 · 희귀 · 영웅 · 전설 · 고대 등급 탭.
- **도감 아이템 탭**: 등급순 정렬, 등급 표시와 얻는 곳.

### 10-6. 저장 호환 (저장 버전 7)

- 제거된 조합 희귀 40종을 가지고 있거나 장착 중이면 제거하고, 그 아이템의 재료 2개 구매가 합만큼 골드를 돌려준다(예: 마검 = 목검 130 + 지팡이 130 = 260 G). 이어하기 직후 한 번 안내한다.
- 원기 토템 · 충전 토템 · 포식자의 엄니 · 굵은 송곳 · 황금 토큰은 희귀 아이템으로 그대로 남는다(강화 단계 유지). 예전 고대 3종은 전설이 된다.
- 대장장이 교환 횟수 등 사라진 상태값은 무시한다.

## 11. 유닛 AI

자동전투에서 AI는 곧 “캐릭터의 연기”다. 원작 웹 버전의 판단 구조를 옮긴 뒤 다듬었다. 전투 난수는 시드 기반이라 같은 조건이면 같은 전투가 재현된다.

### 11-1. 판단 구조

| 단계 | 내용 |
| --- | --- |
| 성격 값 | 유닛마다 대담함 · 신중함 · 반응속도 · 인내심 · 선호 거리 · 좌우 성향을 무작위로 갖는다 |
| 타깃 선택 | 캐릭터별 우선순위(암살자 = 체력 낮은 후열, 개구리 = HP 높은 적 등) + 거리. 도발 · 집중 명령 · 반격 · 엄호가 있으면 우선 |
| 타깃 유지 | 한 번 고른 타깃은 1.6초 이상 유지(사라지거나, 다른 적이 이미 사거리 안이거나, 훨씬 가까울 때만 바꿈) |
| 이동 모드 | 관찰 · 접근 · 선회 · 측면 · 견제 · 후퇴 중 상황에 따라 가중 확률로 |
| 위치 잡기 | 후열은 안전한 “스테이션”, 엄호형은 지킬 아군 곁, 의존형은 기준 아군 근처 |
| 위험 회피 | 폭발 · 장판 · 궁극기 예고 범위를 평가해 피하고, 날아오는 투사체를 옆으로 비킨다 |
| 방어 반응 | 상대의 공격 준비 동작을 보고 패링 / 회피 / 반격 / 버티기 중 확률적으로 고른다 |
| 공격 감지 | 보는 방향(240°)의 준비 동작 · 투사체만 감지. 멀리서 다른 아군을 노리는 근접 공격은 무시 |

### 11-2. 상황 판단 (전술 판단)

유닛마다 매 0.25초 지금 얼마나 대담할지(신중 −1 ~ 저돌 +1)를 다시 정하고, 기존 선택을 그쪽으로 기울인다(`TacticalMind`).

| 요소 | 내용 |
| --- | --- |
| 기본 성향 | 근접형은 저돌적으로, 대치형 · 후열은 신중하게 기운다 |
| HP | 넉넉하면 저돌적으로, 낮으면 신중하게 |
| 전장 상황 | 아군과 적의 수 · 체력을 비교해 유리하면 저돌적으로 |
| 신중할 때 | 거리를 두고, 적이 나를 향해 휘두르는 동안 공격을 미루고, 후딜 순간 들어간다. 패링 · 회피를 더 고른다 |
| 저돌적일 때 | 공격 기회를 더 빨리 잡고, 크게 기울면 틈만 나면 공격. 반격을 더 고른다 |
| 우선순위 | 엄호형은 주변 아군을 공격하는 적, 신중할 때는 나를 공격하는 적, 저돌적일 때는 사거리 근처의 빈사(HP 30% 미만) 적 |
| 경계 | 피해 배율 · 반격 강화 · 타깃 고정 · 선공 대기 같은 성향 고유 효과(6-7)는 플레이어가 고른 성향에만 붙고, 상황 판단으로는 켜지지 않는다 |

### 11-3. 특수 규칙

- **기절한 적**: 타깃이 기절해 있으면 대치형 · 신중함이라도 거리를 재지 않고 바로 다가가 기절이 끝날 때까지 쉬지 않고 공격한다(이동속도 보너스는 없음). 후열은 자리를 지키되 대기 없이 계속 쏜다.
- **그리핀 이동**: 사거리 안에 적이 없으면 기본공격 대시로 다가간다.
- **석궁 연사**: 탄창이 남아 있으면 선공 판단 없이 다음 발을 쏜다.
- **매혹**: 매혹된 유닛은 다른 판단 없이 시전자에게 천천히 걸어간다.

### 13-2. UI 원칙

- **스크롤 없는 화면**: 모든 화면과 창은 휴대폰(360×740, 390×844)과 1280×720에서 스크롤 없이 한 화면에 들어온다. 스크롤은 유닛 목록 · 인벤토리 · 카드 패 · 도감 항목 같은 **목록**에만 허용한다. 넘치면 열 수 · 카드 크기 · 문구 · 한 번에 보여 줄 정보를 줄인다.
  - 이벤트 선택지: 휴대폰 2열(3 · 5개는 3열), 넓은 화면 한 줄 최대 5개.
  - 모집 후보 4장은 휴대폰에서도 가로 한 줄, 상점은 휴대폰 한 줄 3장.
  - 대장장이 재료는 작은 아이템 칸(4~8열), 도박꾼의 방은 마지막 게임 결과만.
- **UI 디자인 시스템**(`scripts/presentation/ui_style.gd`, `ArenaUI`): 세 가지 면만 쓴다.
  - **창**: 2px 테두리, 모서리 16, 깊은 그림자, 위쪽 제목과 둥근 닫기 버튼, 가는 구분선.
  - **카드**: 1px 선, 모서리 12, 그림자 없음(눌리지 않는 정보 묶음).
  - **버튼**: 모서리 12, 밝은 테두리 + 아래 4px 턱(누르면 내려앉음). 주 행동 주황, 일반 강철 파랑, 위험 빨강, 닫기 · 취소는 둥근 버튼. 탭은 어두운 홈 위에 선택 칸만 솟는 세그먼트. 가격 칩: 골드 청동, 토큰 남색.
- 글꼴: 숫자 · 영문 대형 타이포는 Barlow Condensed, 그 밖의 모든 글자는 빗썸고딕 오리지날.
- 톤: 어두운 남색 판타지 + 금색 포인트. 배경은 그라데이션 위 천천히 움직이는 빛 번짐과 입자.

### 13-3. 전투 그래픽

- 유닛 · 투사체 · 이펙트는 도형과 파티클로 그리고, 일부 이펙트는 셰이더 층(`scripts/presentation/shader_fx_layer.gd`, `assets/vfx/fx_*.gdshader`)으로 그린다 — 충격파(굴절 고리), 화상 불길, 번개 연쇄. `CombatPresentation.use_shader_fx`를 끄면 도형 방식.
- HP바 · 궁극기 게이지는 모든 효과 위의 별도 층에 그려 이펙트에 가려지지 않는다.
- 속성 · 상태 표시: 화상 불꽃 · 연기, 맹독 초록 · 보라 연기, 침식 보라 기운, 동상 얼음 가시, 번개 연쇄 스파크, 빛 · 어둠의 오브가 회복 · 흡수 대상에게 날아가는 연출, 광휘 · 암흑 표식, 역풍 · 기류 회오리, 화상 · 맹독 · 기류 개수 배지, 감전 번개 아이콘, 둔화 발밑 고리, 목표 붉은 조준선, 매혹 하트(위로 계속 떠오르는 작은 하트들), 속삭임 바늘.
- 캐릭터 고유 연출 예: 히어로 구조 · 강펀치 충격파, 말뚝 결속 원, 기관차, 자석 전류, 택배, 빙결 폭풍, 그리핀 폭풍 · 돌풍, 슬라임 착지, 앵무새 깃털, 하트 투사체, 역병 안개(지팡이 일격 후 0.6초 만에 맵을 덮는 어두운 안개와 떠다니는 포자), 빙하 골렘 냉기 · 얼음 가시 · 증기 차징 · 폭발, 불의 검사 회전 참격.

### 13-4. 연출 목록

### 15-1. 현재 알고 있는 한계

| 구분 | 내용 |
| --- | --- |
| 아트 | 신규 캐릭터 상당수는 도형 · 생성 아이콘 중심의 임시 아트. 전용 초상화 · 모션이 필요 |
| 사운드 | 배경음악은 있으나 효과음은 거의 없다 |
| 튜토리얼 | 초보 안내 문구 기획(`BEGINNER` 문서)만 있고 게임 내 튜토리얼은 없다 |
| 세계관 | 챕터 이름은 임시. 스토리 · NPC · 대사가 거의 없다 |
| 보스 | 보스 후보가 원작 9종의 강화판뿐. 전용 패턴 · 연출 없음 |
| 신규 캐릭터 연동 | 온천 복권의 “유닛” 보상은 원작 26종에서만 뽑힌다. 일부 특수 상태(말뚝 결속 · 택배 · 자석 연결)는 후퇴 후 재전투 시 이어지지 않는다 |
| 메타 진행 | 런이 끝나면 남는 것이 없다(영구 성장 · 해금 없음, 도감은 전부 열려 있음) |
| 밸런스 | 히어로(구조 패시브) · 슬라임 · 그리핀(1:1)이 강한 편. 신규 캐릭터 일부(역병 · 빙하 골렘 · 불의 검사)는 측정 없이 정한 수치 |
| 고대 아이템 | 탑에서 얻는 경로가 없다 |

### 15-2. 토론할 질문

1. **런 이후에 무엇이 남아야 하는가?** — 계정 레벨, 캐릭터 해금, 시작 길드 선택, 난이도 단계 중 무엇이 맞을까?
2. **플레이어 개입의 양** — 터닝포인트 12초/30초 간격, 초월 충전 속도, 전략카드 6종이 “관전 vs 조작” 균형에 맞는가?
3. **시너지 시스템** — 태그가 지금은 AI 행동에만 쓰인다. 같은 태그 · 속성 2/4명 보너스를 넣을지.
4. **토큰 경제** — 영입이 토큰에만 묶여 있다. 골드 영입을 허용할지, 토큰 획득처를 늘릴지.
5. **보스의 정체성** — 일반 캐릭터 강화판 대신 전용 보스(고유 패턴 · 페이즈 · 맵)를 만들지.
6. **커스텀 전투 확장** — 배치 공유 코드, 비동기 대결, 시나리오(퍼즐) 모드.
7. **신규 캐릭터 방향** — 41종 중 어떤 역할이 비어 있는가.
8. **효과음 우선순위** — 타격감에 소리가 빠져 있다.
