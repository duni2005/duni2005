# 패링·피격·사망·참격·전사 궁극기 표현 개선 — preview.6

## 변경

- 패링 성공: 반경을 나타내는 원형 선을 제거. 청백색 접점 섬광과 세 겹의 넓고 부드러운 방향성 압력 파동, 바깥으로 흩어지는 빛으로 교체했다. 실제 CombatWave 표기도 얇은 원형 경계 대신 반투명 압력파로 표시한다. 준비 중 방어 표기도 작은 빛으로 교체했다.
- 피격: 기본 피격 효과 반경 72→90, 치명타 65→95. 중심 섬광·방향성 스파크·짧은 압력파를 키우고 일반 피격 입자를 7→11개로 늘렸다. 기존 35/55ms presentation freeze는 그대로다.
- 사망: 반경 45→115×개체 scale, 두 겹의 폭발 파동·12방향 섬광·큰 파편. 종료 연출로 넘어가도 이미 발생한 사망 파동이 이어진다. 입자는 기존 전체 640개 한도 안에서 처리한다.
- 참격: 전사·암살자·두비두밤·검객·성기사의 검 차례·광신도에 준비 자세를 일찍 잡고 유지하는 시각 곡선을 적용했다. active 초반에 빠르게 휘두르고, 몸의 당김·반동·겹치는 참격 잔상을 강화했다. 두비두밤 검 분실, 성기사 교대 공격은 실제 상태에 따른다.
- 전사 궁극기: 실제 원본 검 pose를 확대해 준비 동작을 만들고, 실제 swordWave 생성 순간에 큰 휘두르기 동작을 한 번 연결한다. 발사체는 주황·금색 외피/밝은 중심/잔상으로 구성한 초승달 검기다. release pose는 simulation 시간 기준이므로 TP에서 진행하지 않는다.
- 폭 0인 참격 도형을 그리지 않도록 해, 실제 X11 검사에서 발견한 첫 프레임 triangulation 오류를 해결했다.

## MIGRATION_NOTE / 되돌리기

원본보다 큰 파동과 참격은 의도한 표현 변경이다. 실제 공격 범위/상쇄/넉백/시전 타이밍은 그대로이며, 시각적 파동 크기를 공격 판정 반경으로 사용하지 않는다. 전사 궁극기의 release pose는 실제 검기 관측 시 생성하는 짧은 로컬 표시이며 저장하지 않는다.

이번 변경만 되돌리려면 `migration/impact-refinement/before/*.gd.txt`의 5개 변경 파일을 동일 이름 `.gd`로 `scripts/presentation/`에 복원하고 새 마스크 2개를 제거한다. `.gd.txt`를 프로젝트 안에서 다른 `.gd` 이름으로 복사하지 않는다(중복 global class 방지). 웹/APK는 복원한 소스로 다시 빌드한다. 기존 저장 데이터 초기화는 필요 없다. 배포 기준 이전 source commit은 `733fbd905d1d3b8d8c1c4b87105ed2b066dcb67b`다.
