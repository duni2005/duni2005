# 원본 HTML UI 구조 비교 · 정비/배치/전투 수정

사용자가 제공한 원본 화면 8570, 8568, 8564, 8566, 8574와 실제 `dist/` 실행 화면을 기준으로 조사했다. 원본 HTML 파일은 수정하지 않았다. 색상은 이전 요청인 저채도 푸른색을 유지하고, 구조·간격·시각적 계층을 원본에 맞췄다.

## 실제 비교 자료

`migration/layout-parity/html/`은 원본 HTML을 실행해 캡처한 인벤토리, 강화, 메뉴, 배치, 전투 화면이다. 모바일 390×710 및 PC 1280×800에서 각각 캡처했다. 같은 폴더의 `before-mobile-*`, `before-desktop-*`는 이번 작업 전 스크립트를 별도 프로젝트에서 실행한 화면이다. `mobile-*`, `desktop-*`는 수정 후 화면이다. 수정 전 정비 화면에는 대응하는 중앙 메뉴가 없어 메뉴의 전후 캡처를 만들어내지 않았다.

실제 이미지 비교 페이지는 게임의 `/ui-review/`에 제공한다. 전투 시점·적 구성·재화는 각 실행의 fixture 및 RNG에 따라 다르므로 동일 전투의 픽셀 일치 증거로 사용하지 않는다.

| 화면 | 확인된 차이 | 수정 |
|---|---|---|
| 정비 | 커다란 3탭 관리 팝업, 이중 여백 | 원본처럼 별도 페이지형 정비, 인벤토리/강화 2탭, 상단 배치 CTA |
| 길드원 선택 | 큰 격자와 픽셀 초상 중심 | 가로 아이콘 스트립, 개별 HP·기력·장착 슬롯 유지 |
| 인벤토리 | 설명/버튼 위주로 정보 분산 | 선택 유닛/슬롯, 보유 수, 도움말, 모바일 4열/PC 6열 슬롯 |
| 강화 | 긴 스탯 문장 | 이름/Lv, HP/기력, +12/+8/+8/+2 수치 타일, 가격 버튼 |
| 메뉴 | 정비 화면 대응 메뉴 없음 | 배경 흐림 + 중앙 패널 + 메인화면 동작 |
| 배치 | 도구/시작 버튼의 위치·비율 차이 | 전장 아래 네 도구, 작은 카드, 우측 시작 CTA, 정비 아이콘 |
| 전투 | 제목과 기록 버튼 겹침, HUD 밀도 | 좌측 방/우측 기록, 자원바, 좌측 상황/우측 시계, 작은 파티 줄 |
| 전투 조작 | 배속 조작이 일반 화면에 드러나지 않음 | 기존 BattleClock API의 1×/2×/4× 버튼, 우측 붉은 후퇴 |
| 공통 | 과한 테두리/버튼 그림자, 폰트 차이 | 얇은 경계와 평면 패널, 원본 계열 숫자/브랜드 서체, 한국어 폰트 번들 |

원본 `app.js`의 26개 EMOJIS와 테두리 색을 추출해 UI용 아이콘 PNG로 만들었다. 아이콘 출처/색은 `original-unit-icons.json`에 기록했다. UI/배치 아이콘과 실제 전투 픽셀 캐릭터는 분리한다. 사망·구매불가·후퇴의 붉은 표시와 네 개의 작은 배치 도구는 앞선 사용자 요구를 유지한다.

## 코드 경계

새 UI 파일: `unit_icon.gd`, `upgrade_summary.gd`, `modal_backdrop.gd`, `battle_status_line.gd`. 공통 Theme, 브랜드/자원/카드, 길드 관리, 배치, 타워/콘텐츠/전투 화면을 수정했다. 화면은 기존 content_action, 배치, clock.set_speed, TP resolve, 저장 라우팅을 호출한다. UI에서 보상·강화·정산을 새로 계산하지 않는다.

신규 테스트는 `layout_parity_runner.gd`, `layout_audit_runner.gd`다. 기존 BlueTouch 검사의 의도된 화면 기대값만 인벤토리 우선 및 우측 CTA에 맞춰 갱신했다. 테스트를 제거하지 않았다.

## 검증

- Godot 4.6.3 editor import/parse: 오류 없음.
- 기존 전체 회귀: **120,324 검사 / 실패 0**. Phase 10.5 AI golden, Phase 11 save, Phase 12 paired simulation 포함.
- 추가 headless UI 9개 suite: **1,117 검사 / 실패 0**.
- 실제 X11 정비/강화/메뉴/배치/배속/기록/TP 흐름: **72 검사 / 실패 0**.
- 추가 모집/상점/휴식/지도 화면 경계: **12 검사 / 실패 0**.
- 모바일 브라우저 터치: **성공**, console/page 오류 0. 정비/강화/메뉴/배치 복귀/전투/TP 재개/후퇴/지도 복귀 및 가로·짧은 화면을 확인했다. DPR 3에서 CSS 390×844, backing buffer 780×1688, TP 재개 버튼 높이 42px이다. `browser.log`, `parity-dpr3-browser-results.json`에 기록했다. VM 소프트웨어 렌더러의 진행 대기는 DPR 1로 렌더링하며, 물리 휴대전화 FPS 검증으로 주장하지 않는다.
- 비교 페이지: 모바일 15개 선택 화면 및 PC 3열 비교에서 이미지 누락과 가로 넘침 없음.

변경 전 해시 224개 중 213개는 동일하고, 바뀐 11개는 화면/표현 스크립트다. `dist/` 19개 모두 동일하다. 게임 규칙·AI·save 코드·정적 전투 데이터·project.godot은 바뀌지 않았다. `hash-verification.json`, 전후 SHA-256 JSON, 최종 Web manifest에 증거를 남겼다. 사운드 기능/설정은 추가하지 않았다.

## 남은 차이

원본의 초록/주황 UI는 요청에 따라 푸른색으로 유지했다. 전투 캐릭터는 기존 픽셀 렌더러이므로 원본 원형 아이콘과 완전히 같지 않다. 일반 일시정지 버튼은 현재 BattleClock에 대응 상태가 없어 추가하지 않았다. 동작하지 않는 버튼을 그리거나 전투 규칙을 이번 디자인 수정에 섞지 않았다. 모든 이벤트·VFX를 픽셀 단위로 동일하게 재현했다는 뜻은 아니다.
